## v4.1.0 · 立意更贴题、AI 精修局部改稿

本次聚焦「找选题/写标书」的立意质量与改稿体验，另含若干开箱即用与稳定性改进。

### 🎯 找选题：立意与引用文献更贴题
- **AI 逐篇判相关性再立意**：检索到文献后，AI 会先逐篇判断每篇「与你研究方向的相关性」
  （高相关 / 相关 / 弱相关 / 离题），**自动筛掉跑题文献**再来综述研究现状、给候选选题；
  文献列表可按相关性排序、每篇标注相关度。这样立意不再被「高被引但离题」的经典文献带偏，
  据此写标书带入的文献也更聚焦。补充检索也改为对照已有发现来找空白，更有的放矢。

### ✏️ 找选题 / 写标书：生成后「AI 精修」局部改稿
- **想改哪就改哪，不重跑全文**：报告 / 标书生成完毕后，新增「AI 精修」面板。既可以直接写一句
  修改意见让 AI 给出若干处**最小改动**，也可以在左侧源码里**选中某一段**、只让 AI 重写这一段。
- **改动标黄 + 一键撤回**：修改由程序精确替换执行（不会牵动你没提到的内容），改动处在右侧预览里
  **背景标黄**，不满意可**撤回**回退上一步，满意了再导出。涉及引用时仍只用真实文献、不编造链接。

### 🧩 其它改进
- **开箱即用**：全新安装无需自己申请大模型 key 也能直接用——已内置默认模型服务，装好即可开始；

## v4.0.0 大版本 · 打通 Zotero、评审组模拟、学术海报

这是一次大版本更新，汇总了「写标书全流程」「文献工作流」「数据分析出图」的全部改进，并新增「学术海报」模块。重点：

### 🖼️ 新增「学术海报」模块
- **论文一键做成会议海报**：粘贴、上传（Word/PDF/txt）或从「论文初稿 / 数据分析」等模块导入内容后，

### 📚 文献工作流：与 Zotero 打通
- **与本机 Zotero 双向互通**：找选题和写标书都能「🔗 从 Zotero 导入」某个分类的文献，
  也能「🔗 推送到 Zotero」把检索/带入的文献存回（可整池推，也可勾选几篇只推选中的）。

- **找选题可"只用自己的文献"**：文献来源可选「自动检索 / 导入+再补检索 / 只用导入的文献

- **引用悬停看"原文支持句"**：报告和标书正文里每处文献引用，AI 会附上支持该论断的那一句
  英文原文；鼠标悬停即浮出文献题名与这句原话，并自动核验是否确为摘要原文，杜绝编造。

### 📜 写标书：评审组模拟 + 照你的文风写
- **自查升级为「评审组模拟评审」**：4 位虚拟评审专家（同行 / 方法学统计 / 形式审查 /
  挑剔评委）各自独立打分挑问题，再合议出共识报告：每章节 0-10 分评分表、A/B/C 资助建议、
  按严重度排序的问题清单、提交前完善清单；评审侧重按资助类型（青年/面上/地区）自动调整。
- **申报要求覆盖度清单 + 一键修订闭环**：逐项核对 12 项申报要求（✅/⚠️/❌）；评审指出问题的
  章节可「按评审意见修订」或「⚡ 一键修订薄弱章节」，改完「🔁 重新评审」看分数变化。
- **上传"文风样例"照你的文风写**：上传一份满意的 Word/PDF/txt，AI 提炼出可编辑的「文风档案」，
  撰写与去 AI 味时按此风格下笔——只学"怎么写"，不会把样例内容写进你的标书。
- **技术路线图 / 甘特图边写边成图**：研究方案自动画技术路线图、年度计划自动画甘特图，
  且撰写过程中图表一写完整就立即渲染成图，不必等全文结束（导出 Markdown 时保留图表代码）。
- **申报合规提醒**：评审报告末尾固定附上合规须知，对齐基金委对 AI 使用的规范。

### 📊 数据分析：可续跑、图更像期刊图
- **出结果后可「继续对话」反复改**：跑完一次分析后可直接提新需求（换图型、加亚组、换配色、
  对数变换后重跑…），AI 在现有分析基础上改一版并重新执行，不必从头再来。
- **图更接近期刊风格**：图例默认无边框、坐标轴更细、网格更淡；柱状图带黑色描边与误差棒；
  剂量/亚组等有序梯度用同色深浅表示；配色更克制，红/绿只表示"升高/降低"等方向；柱状图数值轴

## v3.0.1 修复

- **修 bug：数据分析不再"一跑就报语法错误"**：此前 AI 写的分析代码经常一执行就崩、自动修正也救不回来。根因是 AI 输出被长度上限拦腰截断，截断后的残缺内容被当成代码执行。现在放宽了长度上限（实测完整分析代码远超旧上限），即使偶发截断或 AI 回复里夹带说明文字，也能正确提取出代码继续执行/修复。

## v3.0.0 大版本 · 更稳、更省心

这是一次大版本更新，汇总了近期两轮「全模块入口打磨」和数据分析成功率专项的全部改进。重点：

### 🛡️ 桌面版的数据与更新
- **项目数据不再丢失**：修复了安装版每次关闭应用后项目列表和保存的工作内容可能整个消失的严重问题；现在数据保存在个人配置目录，重启、升级、重装都不丢。
- **应用会自己提示更新**：从本版起，启动时发现新版本会弹窗询问，点「立即更新」自动下载安装并重启，不用再手动来下载页。
- **统计顾问修好了**：此前「请教 AI」后推荐卡片永远不出现；现在正常显示推荐方法/前置假设/注意事项/替代方法，出错也有可读提示。
- **安装版补上期刊分区与参考文献核验**：安装包此前漏带两份内置数据，导致期刊分区标注一直缺失、参考文献核验可能失败；本版起恢复正常。
- **左侧导航加图标**：与首页一致的图标，折叠侧栏后也能一眼认出各模块。

### 📊 数据分析：更容易一次成功
- **先看真实数据再分析**：AI 先在你的数据上做只读探查（列名、分组、分布），再据此分析，消除「猜错数据结构」这一头号失败原因。
- **统计方法由规则把关**：用哪种检验由程序在真实数据上跑完前提检验（正态性/方差齐性/期望频数）后按规则确定，并以「决策卡」展示依据；AI 不能硬来。
- **出错自动修复更聪明**：带着真实数据诊断修错，反复修不好会换思路重做；Excel 的生存分析/ROC 也打通了。
- **读数据只走一条路 + 数据画像体检**：列名不一致导致的失败已根除；上传后自动标出「文本型数字」「疑似日期/编号列」「未识别的缺失标记」。

### ✨ 全模块入口打磨（两轮）
- **不再有「点了没反应」**：灰色按钮都会说明原因；失败给「重试」且不丢你已有的内容；「清空」有二次确认。
- **结果拿得走**：找选题报告、论文初稿、审稿回复信、选刊清单、分析结论、伦理材料预览……全部可一键复制/导出。
- **工作流连起来**：论文初稿一键去选刊/去排版；数据分析结论一键送排版。
- **回复信可选英文/中文**（默认英文）；伦理材料加必填校验，不再下载空白送审件；实验规划的样本量真正写进方案且与参数自洽。

- **应用内配置向导**：首次打开引导填 API key，可在页面里直接编辑/切换模型并**在线测试 key 是否可用**，不必手动改文件。
- **帮助卡片**：9 个子工具旁的“?”说明何时用、怎么用。
- **病例数据脱敏**：上传含 PHI 的数据时自动检测并脱敏。
- **参考文献导入/导出**：支持 .ris / .bib / .enw。
- 数据分析新增森林图 / KM 生存曲线 / ROC；UI 升级（Toast 提示、Diff 视图、Ctrl+K 命令面板、字体调节、Lucide 图标）。

## 安装与配置
- 下载 `*-setup.exe` 双击安装，终端用户无需安装 Python 或任何依赖。
- 首次打开按向导填入 `LLM_API_KEY`（默认 DeepSeek，也可换硅基流动/OpenAI/Claude）即可；
  配置存于 `%APPDATA%\科研助手\.env`，重装不丢。
- 数据分析、画图、脱敏均在本机完成，数据不出网。
