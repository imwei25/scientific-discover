# 领域调研技能

> **决策规约（照 AGENTS.md §六）**：本技能任何要用户拍板的抉择——方向 / 方案 / 目标刊 / 作图后端 / 纳排标准 / 下一步等——一律**在正文里列 2–4 个编号候选**（推荐项放第 1 个并写明“推荐 X，因为……”），让用户**回一个数字即推进**；**别用开放式提问逼用户打字，也别弹交互选项卡（如 AskUserQuestion）**。只有无法枚举的纯事实（手上的数据文件、伦理批号、代表作清单等）才开放式问。

给一个方向，产出一份能让人 15 分钟看懂现状的**调研简报**。参考 K-Dense scientific-skills 的领域扫描思路。

## 定位（本技能在套件中的位置）
顶层主控（AGENTS.md 常驻指令）负责判意图、定范围、派发；派到本技能就**直接做，别回绕**。产物直接写**当前工作目录**——网关已把本会话的 cwd 指到该会话的产物目录，用裸文件名即可（如 `table1.csv`），别再拼 `outputs/…` 前缀，也别写到仓库根。

## 方法
1. **先界定范围**：跟用户确认方向、时间窗（默认近 5 年）、偏基础还是偏临床、简报篇幅（默认 ≤3000 字、证据池 30–50 篇）。能列成选项的（偏基础 / 偏临床、篇幅档位等）照 AGENTS.md §六 给编号候选、用户回一个数字即定。
2. **抓真实证据 —— 四象限饱和采样，别只按高被引一维**（单看高被引偏向老牌固化工作，会系统漏掉新兴热点/争议/新流派，"看到一角就下全貌结论"）：
   - 检索文献默认用 `literature-review` 的 `search.py`（Europe PMC，国内可达）；`search-lit` 作为有 MCP/境外网络时的增强路径；需要全文再用 `fulltext-retrieval`。
   - **四象限各取若干、合成证据池**：① **高被引**（代表作，按 `citedByCount` 排序，见下）② **近 2 年**（热点/新流派，`--since` 卡近两年）③ **综述 / 指南**（子面骨架，检索式加 review/guideline）④ **争议 / 撤稿**（分歧点）。每象限都取到才算覆盖。
   - **防漏三律**：每个概念用 **≥2 组同义词**检索（如 SGLT2 inhibitor / sodium-glucose cotransporter-2 inhibitor / 具体药名 dapagliflozin…）；先检一轮**综述**归纳"这个领域必须覆盖的子面"（同 `literature-review` 做法）再按子面补检；**做一次邻近领域探针**（如 SGLT2-肾病 要探一下 SGLT2-心衰的溢出证据），别把边界拍死在最窄理解上。
   - **高被引排序**（无需任何 key、国内可达）：`literature-review` 的 `search.py` 已从 Europe PMC 取回 `citedByCount` 列，直接按它排序即可挑高被引/代表文献。
   - **"关键团队/机构"聚合**（可选增强）：想按机构/作者聚合发文量与趋势，用 **OpenAlex**（已装 `pyalex`）：`from pyalex import Works, config; config.email="你的邮箱"; Works().search("主题").sort(cited_by_count="desc").get()`，机构聚合 `group_by("authorships.institutions.id")`。✅ **OpenAlex 只需邮箱（polite pool），不需要 API key**（2026-07 实测：`config.email` 即可匿名调通；`config.api_key="..."` 只是可选提限额，与 openscience 同法）。真连不通（限流/被墙）再退回用上面 Europe PMC 的结果人工归纳团队，并把该节标"未核实，仅供线索"。**绝不凭记忆编团队名。**
   - 有联网时也可用 web 搜索补充综述、指南、会议动态。
3. **从证据池归纳主线**（别凭印象拍流派，要能溯源到证据）：把证据池按 **MeSH / 关键词 / 干预或机制主题**聚成 2–5 组 → 每组挑 2–3 篇代表作 → 命名为一条技术路线/流派 → 填「主线表」（路线 | 代表作 | 优缺点 | 活跃度/趋势）。**热点**须有量化佐证——"发文量或被引的年度趋势上升"（Europe PMC 结果按年计数，或 OpenAlex 时间序列）；无数据支撑的趋势标"印象，待核实"。
4. **综合成简报**，写到 `research_scan.md`。

## 简报结构（主线与空白**表格化**，便于直接接 topic-selection）
- **一句话定义**：这个方向在解决什么问题。
- **为什么重要**：临床/科学意义、需求规模。
- **主线表**：2-5 条技术路线/流派，表格字段 `路线 | 代表作(标题+年+DOI) | 优缺点 | 活跃度/趋势`。
- **近年趋势**：这 3-5 年往哪走（**用发文/被引年度趋势佐证**，无量化的标"印象待核实"）。
- **关键团队 / 机构 / 平台**：谁在引领。
- **争议与未解问题**。
- **空白清单**：3-5 个，表格字段 `空白 | 真空白 vs 疑似未覆盖 | 难度 | 所需资源 | 证据依据`（衔接 `topic-selection`）。
  > ⚠️ **"没搜到" ≠ "空白"（最容易误导选题的坑）**：一个候选空白**必须经 ≥2 组同义词 + 一轮综述反查仍无相关证据**才可标"**真空白**"；否则标"**疑似未覆盖，需换同义词/邻近领域补检**"。且区分「**证据缺失**」（有人做过但结论不清）与「**研究缺失**」（没人做）。**绝不把"本轮没检到"写成"领域空白"**——那会直接误导下游 topic-selection 选一个其实早有大量研究的方向。
- **参考文献**：列真实文献（标题/年份/DOI）。

## 约定
- 产出写 `research_scan.md`。
- **出 PDF（正式报告默认交付版）**：简报写完后，把 `research_scan.md` 交给 `render-pdf-doc` 技能渲染成 `research_scan.pdf`。中文报告务必指定中文字体（`--cjk-font`：本地 `Microsoft YaHei`，服务器 `Noto Sans CJK SC`），否则会漏字。
- 有据可依：能引文献的论断都引；拿不准的标"待核实"，不要言之凿凿。
- **绝不虚构文献、数据或团队名**。联网受限时说明局限。
