# 省级自然科学基金 要求卡（浙江/广东/江苏为样板）

> 口径年份：2025。**文体与 NSFC 高度同构（科学问题驱动），可复用 NSFC 骨架，但篇幅大幅压缩、各省细节不同。** 多数省份的申请书模板锁在省申报平台内（需依托单位账号）——**优先让用户提供本省当年模板/通知，用"指南摄入"流程对齐；本卡提供通用骨架与浙江样板。**

## 1. 正文骨架（浙江省官方撰写提纲，信息最全的一手样板）

来源：https://zjnsf.kjt.zj.gov.cn/isp/staticfiles/ueditor/202409/2025年度浙江省自然科学基金项目申请书正文撰写提纲.docx

一般项目八节：
1. 项目名称
2. 研究工作的科学意义与拟解决的关键科学问题
3. 研究目标（及与申请者长期学术目标的关系）
4. 研究内容、研究方案和进度安排
5. 项目创新之处
6. 工作基础与工作条件
7. 预期研究结果
8. 参考文献（**按 GB/T 7714 著录**）

（杰青类另加：主要学术成绩及影响 + 代表论文 ≤5 篇 / 获奖 ≤5 项目录）

## 2. 字数/格式硬限（浙江口径；其他省以本省模板为准）

- 重大/重点/杰青类正文建议 **≤15000 字**，其它项目 **≤8000 字**（参考文献不计入）——注意比 NSFC 面上短得多，**写作时按此裁剪，别把 NSFC 篇幅直接搬来**。
- 全文 ≤3MB；图片 JPG/JPEG、版式嵌入式；**不得改动模板页眉页脚页码**（边距左右 2.3cm、上下 2.54cm）。
- 网络评审由省外专家负责，**不双盲、无需匿名**。
- 系统按模板生成 PDF 全文，递交前须试生成核查。

## 4. 形式审查要点（跨省共性）

- [ ] 申请人资格与**限项**（广东：无在研主持国家/省重点重大项目；江苏：同年限报一项省计划、在研省计划负责人不得牵头——逐省核对当年通知）
- [ ] 合作协议（多单位时）；伦理审查意见（涉人/动物）
- [ ] 参与人信息真实性；单位盖章与推荐流程
- [ ] PDF 合成单文件、命名规范（如江苏"申报代码-申报人姓名"）
- [ ] 正文未超本省字数硬限、未改模板页眉页脚

## 5. 起草流程要点

1. **先要用户提供本省当年通知+模板**（多数省拿不到公开直链）；有则走"指南摄入"，以用户文件为准。
2. 没有模板时用 §1 浙江骨架起草，显著标注"结构按浙江样板，提交前须以贵省当年模板为准调整"。
3. 内容策略：省基金评审更看重**与本省产业/临床需求的结合**与申请人独立性；篇幅小，逻辑链（问题→目标→内容→方案→基础）要更紧凑，砍综述保方案。

## 6. 动态核实项

- 本省当年申报通知（强度、限项、截止时间、平台入口逐年变）
- 模板版本与字数上限；伦理/盖章等附件要求
