# 学会/基金会临床研究基金 要求卡（吴阶平、CSC 等）

> 口径年份：2023–2025 各期征集通知。**文体：申请表 + 临床试验方案（protocol）混合体——评审最看重研究设计（PICO、样本量、入选速度）与可行性，不是文献综述。起草时联动 clinical-stats（样本量/把握度）与 data-analysis。每期征集通知即该期权威要求，必须以用户提供的当期通知为准。**

## 1. 吴阶平医学基金会科研专项（表格式）

- 官方下载页（.doc 三件套：申请表 2025 新版/中期报告/结题报告）：https://www.wjpmf.org.cn/article/23.html
- 申请表须含：研究目的、学术依据、技术路线、试验流程、资金预算、时间表、可行性（技术/设备/经验/人力）——**表格式短申请表，非长正文**。
- 提交：纸质原件一式肆份正反面打印；Word+PDF 各一份发指定邮箱做**形式审查初评**。

## 2. CSC 临床研究专项基金（中华医学会心血管病学分会，多中心 RCT 型样板)

- 2023 征集通知（含公章）：https://csc.cma.org.cn/attach/0/c063cafcfc164ec19ab573657282da56.pdf ；2024：https://www.bgpcf.net/nd.jsp?fromColId=2&id=704
- 分类：A 类重大临床问题 RCT ≤300 万；B1 类重要临床问题 RCT ≤150 万。
- 申报要求：清晰的研究背景、明确的研究目的及科学依据、研究流程、经费预算、可行性；**PI 须正高职称、限牵头 1 项**；须披露药械上市状态与企业利益关系。
- 评审链：形式审查 → 3 位专家函审（A=80-100 优先 / B=60-79 / C 不资助，同院仅 1 项入围）→ ≥10 位评委终审答辩（>70 分入围）→ 公示 1 个月。
- **经费按里程碑 5 阶段拨付**（伦理通过 25% / 入选 50% 病例 25% / 入选完毕 15% / 随访完毕 25% / 文章接受 10%，末笔与发表期刊档次挂钩）→ **研究计划的时间表必须按这些里程碑倒排**，入选速度估计要有依据（本院/协作网年病例量）。

## 3. 起草要领（区别于基金标书）

- 核心章节按 protocol 逻辑写：研究问题（PICO）→ 设计（随机/对照/盲法）→ **样本量计算（调 clinical-stats，给公式与参数出处）** → 入排标准 → 终点定义（主要/次要终点及测量时点）→ 统计分析计划 → 入选速度与多中心可行性 → 里程碑时间表。
- 可行性论证用**真实病例量数据**（用户提供本院/协作医院年收治量），不虚构。
- 中华医学会总会各专项（如医学会-企业合作专项）**无统一常年模板，随各期征集临时发布**——总会栏目页 https://www.cma.org.cn/col/col40/index.html ；一律以用户提供的当期通知+申请表为准。

## 4. 形式审查要点

- [ ] PI 资质（职称门槛、限项——CSC 正高限 1 项）
- [ ] 伦理批件/受理证明；涉药械的上市状态与利益披露
- [ ] 按当期通知的提交形式（邮箱+纸质份数+装订要求各期不同）
- [ ] 里程碑时间表与拨付节点对齐、入选速度有病例量依据
- [ ] 样本量计算完整（方法、参数、脱落率）

## 5. 动态核实项

- **当期征集通知**（分类、额度、截止、提交方式逐期变；无常年模板）——用户提供或官网/基金会官网查
- 申请表版本（吴阶平 2025 新版之后可能更新）
