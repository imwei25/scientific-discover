# 中国博士后科学基金 要求卡（面上资助为主）

> 口径年份：2026 年度资助指南。**两条铁规矩：① 逐节硬性字数极严；② 正文准双盲匿名（违者 0 分）。**
> 官方来源：《中国博士后科学基金资助指南（2026年度）》（附录一即申请书模板）https://www.chinapostdoctor.org.cn/prod-api/profile/info/fujian/20260104/824e4553-1677-42f4-b39a-54c965adb668.pdf

## 1. 申请书结构（官方模板原文）

**一、个人信息**
1. 申请人基本情况（系统自动填报）
2. 科研成果和奖励（**限 5 项**，分论文/项目课题/图书/授权专利/获奖五类表格）

**二、项目信息**（正文六节，**逐节硬性字数**）：

| 节 | 字数硬限 |
|---|---|
| 1. 选题依据 | ≤1000 字 |
| 2. 研究内容 | ≤2000 字 |
| 3. 研究方案 | ≤2000 字 |
| 4. 特色与创新之处 | ≤1000 字 |
| 5. 研究计划及预期成果 | ≤500 字 |
| 6. 研究基础 | ≤1000 字 |

**字数计数口径**：在线系统按输入框**字符数（含标点、不含空白）**计。自查时按此口径数，且**Markdown 标记、`[待补充]` 占位符不计入**——但要留出余量：用户填入真实细节（刊名卷期、伦理批号、纳排细则）后字数会涨，起草时各节建议写到硬限的 70–85%。

另：项目名称、项目来源（自选/合作导师项目/自主获得课题/其他）、一二级学科+交叉学科、关键词 ≤5 个。

**"项目来源"怎么定**：这个字段影响"创新能力"里的选题自主性评分，但**属申请人才知道的事实，不能替他判断**。起草时列四个选项让用户选（照 AGENTS.md §六），并说明差异：选题由申请人在前期工作上自行延展、仅借用导师资源 → 通常填"自选"；方向本身是导师课题组既定布局、申请人为执行人 → "合作导师项目"；已通过其他渠道单独立项 → "自主获得课题"。用户选定后据此调整"研究基础"节对独立性的表述，**不要为了拿分诱导用户填"自选"**。

## 2. 匿名化铁律（准双盲）

- **"二、项目信息"（研究基础除外）不得出现任何可识别申请人身份的信息**——姓名、设站单位、合作导师姓名等，**违者该项计 0 分**。
- 起草时对正文做匿名扫描：把"本人/申请人在 XX 大学随 XX 教授……"改为"申请人前期工作表明……"式表述；单位/导师信息只允许出现在"研究基础"节与个人信息部分。
- 可仿照 render-pdf-doc 的 `redact_internal` 思路做定稿前匿名自查。

## 3. 提交形式硬规定

- 申请书**只能由"中国博士后科学基金管理信息系统"在线生成；网下生成/上传下载模板均视为无效申请**——本技能产出的是各节文字内容（供粘贴进系统），不是最终申请书文件。
- 中英文均可；上传文档不得加密。

## 4. 评审权重（指南表 1，内容配比直接照此倾斜）

- **学术绩效 30 分**（成果 5 项要挑最能证明独立能力的）
- **创新能力 60 分**（创新性/选题自主性/学科交叉——正文的绝对重心；"项目来源"选"自选"对选题自主性有利，如属实）
- **研究基础和条件保障 10 分**

## 5. 资助额度（2026 口径）

- 面上：自然科学 8 万 / 社科 5 万；特别资助：18 万 / 15 万（会议评审，另有成果证明材料上传要求）。

## 6. 定稿自查清单

- [ ] 六节各自未超字数硬限（500–2000 字，逐节数）
- [ ] 项目信息部分（除研究基础）**零身份信息**：无姓名/设站单位/导师名
- [ ] 成果 ≤5 项且归入正确类别表格
- [ ] 关键词 ≤5 个；学科代码到二级
- [ ] 内容配比对齐 30/60/10 权重，创新性论述最重
