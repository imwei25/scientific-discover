# 国家重点研发计划 要求卡（科技部）

> 口径年份：2024/2025 模板。**文体与 NSFC 完全不同：任务/指标驱动，无"科学假说"叙事主线——不要套 NSFC 骨架。** 各重点专项的申报指南可覆盖本卡，起草前必读目标专项当年指南及其所附"形式审查条件要点"。
> 官方来源：任务申报书模板（华东理工转载，科技部制）https://kjc.ecust.edu.cn/_upload/article/files/3f/5a/2dd912a446ef9bd4fdc8a9c73f4d/3657c9e9-bd1d-43ed-ae27-b597c3d8c4ad.pdf ；填报系统 https://service.most.gov.cn

## 1. 申报书结构（填报说明原文八大部分）

① 国内外现状及趋势分析 ② 研究目标及内容 ③ 申报单位及参与单位研究基础 ④ 进度安排 ⑤ 项目组织实施、保障措施及风险分析 ⑥ 研究团队 ⑦ 经费预算 ⑧ 指南所要求的附件

## 2. 正文细分与硬性字数（模板实测）

| 节 | 字数/形式硬限 |

| 项目目标及考核指标 | ≤2000 字 + **表4"项目目标、成果与考核指标表"（立项时/中期/完成时三栏指标值）** |
| 成果呈现形式 | ≤1000 字 |
| 主要研究内容 | ≤3000 字 |
| 研究方法 | ≤2000 字 |

## 3. 格式硬规定（→ 传给 render-docx/render-pdf-doc）

- 标题**黑体四号**，正文**宋体小四**，行距 **1.5 倍**
- 不填写的栏目写"无"；外来语首次出现须注全称；单位名称须与公章完全一致

## 4. 写作要领（与 NSFC 的本质差异）

- 主线是**对标指南方向 + 可考核指标**：每个目标必须落成可量化的考核指标（立项/中期/完成三个时点的指标值），评审对着表打分。
- "领跑/并跑/跟跑"对标表要诚实——虚高自评在函评容易被同行戳穿。
- 课题分解逐课题写满固定提纲，任务分工落到具体参与单位。
- 申报书**不得低于预申报书的考核指标、不得自行调整主要研究内容**（正式申报对预申报的锁定）。

## 评审在乎什么（评价维 —— 起草/评审时按此分配笔墨）

本渠道任务/指标驱动，评审对着**考核指标表**打分，**不看科学新颖性**——这是与 NSFC 最大差异。按重要性排：
1. **考核指标是否可量化、可考核、可达成**——表4 立项/中期/完成三时点的指标值要具体、可测评、能兑现；虚高或无法测评的指标是第一硬伤。评审第一眼看的锚点。
2. **与指南方向的关联度**——是否精准对标目标专项当年指南方向；跑题或只做宽泛响应减分（§2 里"与指南方向的关联关系"单列 ≤1500 字就是为此）。
3. **技术路线先进性与可行性**——路线能否支撑指标达成；"领跑/并跑/跟跑"对标要诚实，虚高自评在函评易被同行戳穿。
4. **任务(课题)分解合理性**——课题分解落到具体参与单位、分工与考核指标闭环，别只在总述里空谈。
5. **研究基础与团队/单位配套**——牵头 + 参与单位的基础与平台撑得起任务量。

**淡化/别浪费笔墨**：NSFC 式"科学假说 / 科学问题凝练"叙事主线、宏大科学意义铺陈、跟热点表态——本卡任务/指标驱动，别套 NSFC 骨架。**主动谈风险与缓解**（§1 第⑤部分明列风险分析）是加分。

## 5. 预算

- 按单位分列（牵头/参与单位各自预算），配合作协议；参照《国家科技计划项目资金管理办法》科目编制，每条写测算依据。

## 6. 形式审查要点

- [ ] 申报资格与**限项**（可在 service.most.gov.cn 预查在研项目）
- [ ] 牵头/参与单位**合作协议**齐、单位名称与公章一致
- [ ] 负责人**诚信承诺函**
- [ ] 考核指标不低于预申报书、研究内容未自行调整
- [ ] 各节未超字数硬限、强制表格齐全
- [ ] 按目标专项指南所附"形式审查条件要点"逐条过（每个专项不同）

## 7. 动态核实项

- 目标专项**当年申报指南**（方向、指标要求、形式审查要点逐专项逐年变）——高校科研院转载页或 service.most.gov.cn
- 模板版本（以指南附件为准）；限项规定；申报截止时间
