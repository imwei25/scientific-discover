# NSFC 要求卡 —— 经典版提纲（重点、青年A/B 类等未改版类别适用）

> 口径年份：2024/2025 版提纲；2026 年面上与青C 已改用新三段式（见 [nsfc-2026.md](nsfc-2026.md)）。**用本卡前必核**：目标类别当年模板是否仍为此结构——以申请人从填报系统下载的当年正文模板为准。
> 官方来源：《撰写范例（2024版）》PDF（苏州城市学院转载）https://www.szcu.edu.cn/_upload/article/files/f7/d5/3ccd83054580a9da0a2673ae1c96/089639c3-69f1-4442-af54-5f5314ae28a7.pdf

## 1. 结构提纲（官方原文，勿删改提纲标题及括号中的文字）

- **（一）立项依据与研究内容（4000-8000 字）**
  1. 项目的立项依据（研究意义、国内外研究现状及发展动态分析，结合科学研究发展趋势论述科学意义，或结合国民经济和社会发展中迫切需要解决的关键科技问题论述应用前景；**附主要参考文献目录**）
  2. 项目的研究内容、研究目标，以及拟解决的关键科学问题（**此部分为重点阐述内容**）
  3. 拟采取的研究方案及可行性分析（包括研究方法、技术路线、实验手段、关键技术等说明）
  4. 本项目的特色与创新之处
  5. 年度研究计划及预期研究结果（包括拟组织的重要学术交流活动、国际合作与交流计划等）
- **（二）研究基础与工作条件**
  1. 工作基础（与本项目相关的研究工作积累和已取得的研究工作成绩）
  2. 工作条件（包括已具备的实验条件，尚缺少的实验条件和拟解决途径，包括利用国家实验室、国家重点实验室和部门重点实验室等研究基地的计划与落实情况）
  3. 正在承担的与本项目相关的科研项目情况（注明资助机构、项目类别、批准号、名称、金额、起止年月、与本项目关系及负责内容）
  4. 完成国家自然科学基金项目情况（**研究工作总结摘要限 500 字** + 成果详细目录）
- **（三）其他需要说明的问题**（4 小条，如没有填"无"）

## 2. 写作配比要领

- 逻辑链闭环：问题 → 假说 → 目标 → 内容 → 方案一一对应；"研究内容/目标/关键科学问题"一节是评审重点，篇幅与打磨优先。
- 创新点写"与现有工作比新在哪"，不罗列会做什么；可行性用前期数据/预实验/平台条件支撑。
- 立项依据引**真实文献**并附参考文献目录（配合 search-lit 检索、reference-check 核查）。

## 评审在乎什么（评价维 —— 起草/评审时按此分配笔墨）

评价维与 2026 版完全相同，直接套用 [nsfc-2026.md](nsfc-2026.md) §2.8：**科学问题凝练 / 创新增量（与现有工作比新在哪）/ 研究基础与可行性 / 科学意义与潜在价值 / 申请人水平**；淡化技术路线繁琐罗列与跟风热点，主动谈风险与缓解为加分。

### 本渠道的立项依据长什么样（把公共卡 [rationale-and-innovation.md](rationale-and-innovation.md) 的五段骨架按本渠道调权重）

评价维同 2026，五段骨架照搬；差别在**篇幅与栏位**：

- 「立项依据与研究内容」4000-8000 字，失效分析的**绝对字数**上去了，**占比不变**（35-40%）——多出来的字给"多写几项对照工作"，不是给"多铺背景"。
- 有独立「拟解决的关键科学问题」栏 → 公共卡 §4 那句可证伪命题**单列进去**，别在立项依据里重复展开。
- 「特色与创新」独立成节 → 五要素完整写，每条追溯到 `closest_work.md` 的某一行。
- **须附主要参考文献目录**：这使"引文承载率"更要紧——目录里列的每篇，正文最好都在承担失效点论证，只在目录露一面的引用是充数。
