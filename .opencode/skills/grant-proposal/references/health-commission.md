# 省卫健委科技项目 要求卡（卫生健康科研课题）

> 口径年份：2025。**文体：小额表格化短申报书（2–20 万），重点在合规而非长篇论证。模板普遍锁在各省申报平台内（需依托单位账号）——默认"栏目骨架内置 + 正式模板由用户提供"。**

## 1. 正文栏目骨架（自江苏省卫健委医学科研课题申报书还原，各省大同小异）

1. 立项依据
2. 科研假说或技术构思
3. 主要研究内容
4. 关键技术
5. 研究目标
6. 研究方法
7. 现有工作条件和基础

各栏目为表格单元格式短文（数百字级），**不是 NSFC 式长正文**——写作要短平快：一句话立论、假说明确、方法可落地。

## 2. 典型盘子与限项（湖北 2025-2026 样板，逐省不同）

- 重点项目 20 项 × 20 万、面上 200 项 × 2 万、青年人才 100 项 × 2 万
- **牵头限 1 项、参与 ≤2 项；有未结题在研课题的负责人不得新申请**
- 无纸化申报走省级管理平台；签章附件扫描 PDF 上传
- 通知：https://wjw.hubei.gov.cn/zfxxgk/zc/gkwj/ywh/202503/t20250318_5579161.shtml

## 3. 起草流程要点

1. **先要用户提供本省当年申报通知 + 从平台下载的申报书模板**（走"指南摄入"，以用户文件为准）；拿不到时用 §1 骨架起草并显著标注"栏目按通用骨架，提交前以贵省平台模板为准调整"。
2. 医学课题几乎必涉伦理：**提前提示伦理审查意见/批件**为形式审查件。
3. 小额度预算别写大盘子：按省通知科目据实列支，金额与 2–20 万量级匹配。

## 评审在乎什么（评价维 —— 起草/评审时按此分配笔墨）

小额（2–20 万）表格化短申报书，重合规与实用、非宏大科学问题。按重要性排：
1. **临床实用性 / 可落地性**——评审看能不能解决本省 / 本院一个实际临床问题；小额短课题不吃"宏大科学问题"那一套。
2. **可行性（本单位条件）**——数百字的"现有工作条件和基础"要实打实，2 万级面上 / 青年尤其看能否低成本按期做完。
3. **限项与伦理合规**——牵头 / 参与项数、在研未结题冲突、伦理批件是形式审查硬门槛，缺则直接出局（见 §4）。
4. **假说明确、方法可落地**——短平快文体：一句话立论、假说清楚、方法接地气，比长篇论证更得分。

**（据渠道特点与文体归纳，非官方评分表）**

**淡化**：NSFC 式长篇立项依据与国际前沿铺陈；与小额度不匹配的大盘子预算。

## 4. 形式审查要点

- [ ] 限项：牵头/参与项数、在研未结题冲突（按本省当年通知核）
- [ ] 伦理审查意见（涉人/动物）
- [ ] 单位盖章、签章附件 PDF 齐
- [ ] 申报书用平台内当年模板填报（本技能产出为栏目内容，供粘贴）
- [ ] 预算量级与资助强度匹配
