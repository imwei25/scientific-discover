# 医院院级科研基金 / 青年培育基金 要求卡

> 口径年份：2023–2025 公开样本。**绝大多数院级基金只发在医院内网/OA，公网查不到——本卡是归纳骨架，不是某家原文。默认流程：先请用户提供本院当年通知与申请书模板（走 SKILL.md 第 2 步指南摄入），拿不到才用本卡骨架起草并显著声明。**
> ⚠️ 头部三甲（协和、华西、中山、湘雅等）的院级基金模板公网无公开下载，需院内账号——**未找到公开来源**，别假称知道其格式。

## 1. 通用栏目骨架（归纳自公开样本，非某家原文）

1. 封面/简表：项目名称、负责人、科室、职称/学位/出生年月、联系方式、申请金额、起止年月、项目类别（面上/青年/护理/管理）
2. 立项依据与国内外研究现状（含参考文献）
3. 研究目标、研究内容与拟解决的关键问题
4. 研究方案/技术路线/可行性分析
5. 特色与创新
6. 年度研究计划与**预期成果**（院级基金普遍把"发表 1 篇核心/SCI"写成结题硬指标，须写实、别夸口）
7. 研究基础与工作条件（本院设备、**病例量**、既往课题）
8. 项目组成员及分工
9. 经费预算（额度小、栏目简化）
10. 科室意见 / 科研处形式审查意见 / 院领导审批
11. 附件：伦理批件或受理证明、学历职称证明、代表作、（部分院要求）**科技查新报告**

## 2. 相对国自然的特点（决定写作策略）

| 维度 | 国自然 | 院级基金 |
|---|---|---|
| 篇幅 | 正文数万字 | A4 数页；栏目短，靠版式约束（常见宋体小四、左侧装订） |
| 额度 | 20–60 万+ | **0.5–5 万为主**，个别到 10 万 |
| 期限 | 3–4 年 | **多为 2 年** |
| 评审 | 通讯评审+会评 | 形式审查 + 院内专家评审，**常带 3 分钟 PPT 答辩** |
| 评审重点 | 科学问题凝练、创新性、国际前沿 | **可行性（本院能否落地）、临床实用性、申请人成长性、结题产出可达成性**——"能不能 2 年内出 1 篇核心"权重高 |
| 限项 | 复杂多层 | 简单粗暴：每人每年 1 项、每科室 ≤2 项 |
| 排他条款 | — | **"已主持国自然/省基金者不得申报"是院级青年基金的典型条款**——定位就是"未获上级课题者的培育" |

**写作策略**：别照搬国自然那套"国际前沿+宏大科学问题"，评审是本院同行，看的是**你科室的病例量能不能支撑、2 年能不能做完、产出承诺现不现实**。创新点写"本院尚无/本地人群未验证"这种务实定位比吹国际首创更得分。

## 评审在乎什么（评价维 —— 起草/评审时按此分配笔墨）

评审是**本院同行**（形式审查 + 院内专家评审，常带 3 分钟 PPT 答辩），提炼自 §2 "评审重点"行。按重要性排：
1. **可行性（本院能否落地）**——你科室的病例量 / 设备 / 既往课题撑不撑得起、2 年能不能做完，是第一权重；用本院真实数据说话。
2. **临床实用性**——解决本院 / 本地一个实际临床问题；创新点写"本院尚无 / 本地人群未验证"这种务实定位，比吹国际首创更得分。
3. **结题产出可达成性**——"能不能 2 年内出 1 篇核心 / SCI"权重高；产出承诺要写实、与研究体量和 2 年周期匹配，别夸口（院级基金普遍把它写成结题硬指标）。
4. **申请人成长性**——院级青年基金定位是"未获上级课题者的培育"，评审看这个人值不值得扶。

（若带 3 分钟 PPT 答辩，汇报把上述四点讲清即可。）

**淡化**：照搬国自然的"国际前沿 + 宏大科学问题"叙事——评审是本院同行，宏大叙事不加分反显不接地气。

### 本渠道的立项依据长什么样（把公共卡 [rationale-and-innovation.md](rationale-and-innovation.md) 的五段骨架按本渠道调权重）

评审是**本院同行**，五段骨架整体"降半个身位"，全部落到本院可核实的事实上：

- **痛点**：本科室的真实病例量、现行流程里卡住的那一步、造成的具体代价（等待时间、重复检查、转诊率）。同行知道你科室什么样，写虚了当场露怯。
- **失效分析**：对标**本院现行流程 / 指南在本院执行时的失效点**（设备不可及、人手、病例构成与指南人群不符），文献对照 1-2 篇足矣。
- **创新点务实**：写"本院尚无 / 本地人群未验证 / 现行流程未评估过"，**别吹国际首创**——本卡已列为淡化项，宏大叙事在院内评审是减分。
- **价值锚**接结题产出承诺：改变本院哪个做法 + 2 年内能出什么（与体量匹配，别夸口）。


## 4. 自查清单

- [ ] 已请用户提供本院当年通知/模板；未提供的按本卡骨架并声明"非本院官方结构"
- [ ] 限项与排他条款已提示核对（每人 1 项、科室 ≤2 项、已获上级课题是否排除、近 N 年已获院内立项是否排除）
- [ ] 年龄/职称/学历门槛已核（青年基金常卡出生年月）
- [ ] **预期成果写实**：结题硬指标（几篇什么级别期刊）与研究体量、2 年周期相匹配，别承诺做不到的
- [ ] 可行性用**本院真实病例量/设备/既往课题**支撑（用户提供的真实数据）
- [ ] 伦理批件或受理证明、（如要求）科技查新报告已提示准备
- [ ] 版式按通知要求（常见 A4 宋体小四、左侧装订、纸质份数、电子版命名规则）
- [ ] 如需 PPT 答辩，已提示用户准备 3 分钟汇报要点

## 5. 动态核实项

- 本院当年通知（额度、类别、限项、年龄卡点、截止、模板版本逐年变，且**分片区用不同模板**）
- 结题产出硬指标（论文级别要求）；是否需科技查新报告
