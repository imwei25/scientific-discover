# 中医药科研项目 要求卡（国家局 + 省级）

> 口径年份：2025–2026。⚠️ **调研时 natcm.gov.cn（国家中医药管理局官网）多次连接失败**，凡下标"正文未抓取"的条目只确认了标题与 URL，要点来自政府门户或高校转载——**起草前须重新核对原文**。
> 中医药类还有另一条路：走 NSFC 医学科学部十处（H31 中医学 / H32 中药学 / H33 中西医结合），其准入规则见 [nsfc-medical-h.md](nsfc-medical-h.md) §4。

## 1. 国家级入口（现行可查的三类）

**① 国家重点研发计划"中医药现代化"重点专项**（国家局层面体量最大的竞争性计划）
- 2025 年度指南通知（国家中医药管理局，2025-07-15）；官方页未抓取，二手转载：湖南省政府"政企通" http://www.hunan.gov.cn/zqt/xmsb/202507/t20250718_33743386.html ｜上海科委 https://stcsm.sh.gov.cn/zwgk/kyjhxm/xmsb/20250723/733d069d867b4f8cb7ba68abb961f715.html
- 三类项目：公开竞争 / 定向择优 / 青年科学家。参与单位一般项目 ≤10 家、青年项目 ≤3 家。
- 负责人：一般 ≤60 岁；青年项目**男 ≤40 岁、女 ≤43 岁**，须高级职称或博士学位，每年投入该项目 ≥6 个月。
- **材料四件套**：正式申报书（网上填报）+ **联合申报协议** + 诚信承诺书 + **科学数据汇交承诺书**。
- 申报系统 https://service.most.gov.cn ；2025 年度受理 07-21 08:00 至 09-02 16:00。
- **走的是国家重点研发计划标准格式**（预申报书/正式申报书），与 NSFC 申请书完全不同 → **结构按 [most-key-rd.md](most-key-rd.md) 写**，不要套 NSFC 骨架。

**② 全国性专款 / 局机关专项**：科技司征集承担单位公告 http://www.natcm.gov.cn/kejisi/gongzuodongtai/2025-07-17/36645.html （正文未抓取）；"中医药现代化"重点专项项目建议征集 http://www.natcm.gov.cn/kejisi/gongzuodongtai/2025-02-13/35832.html （正文未抓取）

**③ 人才与传承类**：《2021 年全国名老中医药专家传承工作室建设项目实施方案》 http://www.natcm.gov.cn/renjiaosi/zhengcewenjian/2021-11-04/23081.html （正文未抓取）。注意**"名老中医经验传承"不是科研申报书里的栏目，而是独立项目类别**。

⚠️ **"中医药科技发展计划""中医药创新团队"作为国家局常设公开申报计划：未找到现行有效的官方申报通知**——技能不得凭常识杜撰。国家局层面现行可查的经费入口就是上述三类。（"中医药创新团队"在**省级**确有设置，如湖北。）

## 2. 省级样板

**① 浙江**（信息最完整，官方一手）
- 《浙江省卫生健康委办公室关于开展 2026 年度省中医药科技计划申报工作的通知》**浙卫办发函〔2025〕32 号**：https://wsjkw.zj.gov.cn/art/2025/7/3/art_1229560650_2556903.html （⚠️ 发布日期在不同来源间有出入：省网页 2025-07-03、另见 2025-06-16 / 06-12，**需核实**）
- 类别：示范区科技共建项目（重大/重点/青年科学家）+ 面上项目（**中医药临床研究计划、健康服务研究计划**）
- 条件：省内在职、年龄 ≤60 岁；青年科学家 ≤40 岁；示范区项目须高级职称或博士；**牵头 ≤1 项、参加 ≤1 项**；已有在研项目 1 项及以上、或近 2 年有撤题/结题者不予受理
- **材料**：申报书、**可行性报告（独立文档）**、科研诚信承诺书、**伦理审查报告**（涉人体研究）、动物资格证明、研究条件证明
- **硬红线**：可行性报告**重复率 >30% 不予受理**，查重稿最多上传替换 3 次 → 起草时就要提醒用户，AI 辅助内容尤其要实质性重写
- 配套：示范区项目 ≥1:3，其他立项项目 ≥1:1；无资助项目单位给 3 万支持。系统 https://zycc.wsjkw.zj.gov.cn ｜高校转发对照 https://kyc.zcmu.edu.cn/info/1004/5612.htm

**② 湖北**（省局原文未抓取，以下为高校转发二手）
- 转载：湖北中医药大学 https://kxjsc.hbucm.edu.cn/info/1299/9421.htm ｜长江大学 https://kxyj.yangtzeu.edu.cn/info/1092/8303.htm
- 类别：重大、重点、面上、青年人才、指导性 + **省级中医药创新团队**；**全部限额申报**（如长江大学：重点 1、面上 1、青年人才 1、指导性 2）
- 条件：重点/面上/指导性——副高或博士、≤58 岁；青年人才——≤42 岁、硕士及以上、副高及以上；**省卫健委资助尚未结题的负责人不得申报**；负责人限报 1 项、参与 ≤2 项
- 周期 ≤2 年；重点 ≤20 万、面上/青年 ≤10 万
- 申报书在"湖北省中医药管理局科研项目管理系统"填写；部分项目须**在线填写匿名送审版**（盲评）；部分须报**纸质定稿一式五份**
- 研究方向（中医药特色导向）：中医优势病种及中医药防治重大/疑难/罕见疾病的诊疗技术方案；**中医原创理论、中药作用机理**；围绕**"一县一品""十大楚药"**的功效成分与生物活性；**基于经典名方的中药新药研发**

⚠️ **两省《申报书》《可行性报告》的逐栏目模板未找到官方来源**（均在登录制申报系统内分发）→ **技能不得虚构栏目名**，按 SKILL.md 第 2 步请用户从系统导出模板。

## 3. 与 NSFC 结构的差异（可确证部分）

1. **"中医理论依据"在 NSFC 不是独立栏目，却是实质受理条件**：十处要求在中医药学理论指导下立题，"不资助无中医药研究内容的项目""不资助非自然科学属性的中医药研究项目"。
2. **NSFC 独有的披露义务**：研究中药复方或针灸穴位的，**须在申请书中介绍处方组成或相关穴位**；不便公开的走**保密信函**寄科学处并在申请书说明。其他 H 代码没有这项。
3. **"证候标准"在 NSFC 以代码+重点方向体现，无独立栏目**：H3103 证候基础为二级代码；十处重点方向含"治未病理论和证候的生物学基础""病证结合的动物模型""宏观与微观辨证的结合""符合中医临床特点的疗效评价方法学""经典方剂配伍规律及功效物质基础""经穴特异性、腧穴配伍规律与针刺手法"。
4. **省级/国家局相对 NSFC 的结构性差异**：材料形态多一份**独立可行性报告**（浙江）；浙江设 **30% 查重红线**（NSFC 无公开阈值）；湖北要**匿名送审版 + 纸质五份**（NSFC 已全面无纸化）；方向直接约束到中医优势病种、原创理论、经典名方、道地药材；国家重点研发专项额外要**科学数据汇交承诺书 + 联合申报协议**。

## 评审在乎什么（评价维 —— 起草/评审时按此分配笔墨）

中医药项目评审比通用医学项目多一层"中医药属性"闸——理论依据与特色不到位，方法再漂亮也过不了。按重要性排（含官方条件与据渠道特点归纳，已分别标注）：
1. **中医理论依据是否扎实**（官方——实质受理条件）——须在中医药学理论指导下立题。走 NSFC 十处的原文即"不资助无中医药研究内容的项目""不资助非自然科学属性的中医药研究项目"，故走 NSFC 还须**同时具自然科学属性**（官方，见 §3）。
2. **中医药特色**（据渠道特点归纳，非官方评分表）——是否落在经典名方/证候/道地药材（"十大楚药""一县一品"）、中医优势病种、中医原创理论等特色方向；省级方向直接约束到这些点（湖北原文，见 §2）。
3. **临床价值与研究方案严谨性**（据渠道特点归纳）——防治重大/疑难/罕见疾病的临床价值、设计与样本量是否站得住；证候研究是否有可操作的证候标准与疗效评价方法学。
4. **合规与形态门槛**（官方——各渠道硬规定）——处方/穴位披露义务（NSFC，或走保密信函）、独立可行性报告与 30% 查重红线（浙江）、匿名送审版（湖北）、伦理审查报告。

**淡化/别浪费笔墨**：脱离中医药理论的纯西医机制堆砌（走十处会被判"无中医药研究内容"）、臆造的证候栏目名。**把中医理论依据与自然科学属性讲透**是过闸关键，别当背景一笔带过。

## 4. 自查清单

- [ ] 走哪条路已定：NSFC 十处（H31/H32/H33）／国家重点研发"中医药现代化"／省级中医药计划——三者结构完全不同
- [ ] 走 NSFC：确认具**自然科学属性**、有实质中医药研究内容；处方/穴位已披露或已走保密信函
- [ ] 走国家重点研发：按 [most-key-rd.md](most-key-rd.md) 结构；材料四件套齐；年龄与投入工时达标
- [ ] 走省级：类别与限额已核；年龄/职称线；在研未结题冲突；**独立可行性报告**已备（浙江）；**查重率 <30%**（浙江）；匿名送审版与纸质份数（湖北）
- [ ] 伦理审查报告（涉人体）、动物资格证明已备
- [ ] 申报书栏目以**系统内当年模板**为准，未使用臆造栏目名
