# 公共卡 · 立项依据论证骨架 & 创新点构造（跨渠道内核，起草前必读）

> 这张卡不管格式、不管字数硬限、不管形审——那些在渠道卡里。**这张卡只管一件事：让稿子不空洞。**
> 渠道卡决定"写成什么样子"，本卡决定"写出什么内容"。两张一起读。

## 0. 空洞是怎么产生的（先认清失败模式）

不给论证方法时，默认写法必然退化成**综述式罗列**：

> "XX 病发病率逐年上升，严重威胁人类健康。已有研究表明 A 与 B 相关[1]。Smith 等发现 C 通路参与其中[2]。国内李某等报道了 D 的作用[3]。然而，其具体机制尚不清楚，亟待进一步阐明。"

这段话的每一句都"没错"，但评审读完不知道：**到底哪一步卡住了？为什么至今没解决？你凭什么能解决？**
病根在于——**它把文献当成了背景板，而不是论敌**。文献在立项依据里的唯一职责，是**替你论证"现有解法在什么条件下失效"**；不承担这个职责的引用，就是填充物。

本卡把论证拆成 5 个可执行动作：**读上游 → 建对照表 → 归因 gap → 锁科学问题 → 按骨架落笔**。

---

## 1. 第一件事：读上游产物，别从零捞文献

grant 流水线（research-scan → topic-selection → novelty-check → 本技能）的上游已经把最贵的活干完了。
**起草前先扫当前工作目录**，命中就直接映射，别重新做一遍泛综述：

| 上游产物（典型文件名） | 出自 | 映射到本卡的哪一步 |
|---|---|---|
| 《新颖性裁定记录》`novelty_verdict*.md` | `novelty-check` | 「最接近的文献表」→ §2 对照表；「差异点陈述」→ §5 创新点；四种裁定（真新颖/增量/已被回答/有争议）→ §3 gap 归因 |
| `research_scan.md`（主线表、争议与未解问题） | `research-scan` | 主线表 → §2 对照表的候选行；争议节 → §3 归因"证据互斥" |
| `topic_selection*.md`（打分与收敛理由） | `topic-selection` | 选题为何胜出的理由 → §4 科学问题、§6 价值段 |
| `evidence_table.csv` / 综述稿 | `literature-review` | 抽出**最接近的 5 篇**填对照表，其余不进立项依据 |

**一条都没命中**（用户直呼本技能、跳过了上游）→ 现场补一轮**针对性检索**，不是泛综述：
- 用 `literature-review` 的 `search.py`（Europe PMC，国内可达）或 `search-lit`，目标只有一个——**找出与本课题最接近的 3–5 项工作**，读到能回答"它在什么条件下失效"的程度（必要时 `fulltext-retrieval` 取全文）。
- 检索式围绕**你的科学问题**构造，不是围绕疾病名。查"XX 病"会捞回一万篇背景；查"XX 病 + 你要判的那个具体决策/机制层次"才捞得回论敌。
- ⚠️ **绝不凭记忆写文献**。查不到最接近工作 → 如实说"未检索到直接对标工作"，并在 §3 按"概念未提出"归因，而不是编一篇出来当对照物。

## 2. 最接近工作对照表（**必产物，无表不许写创新点**）

写到当前工作目录 `closest_work.md`（裸文件名），≤5 行。这是整份立项依据的地基：

| 最接近工作（作者/年/引文） | 它回答了什么 | **它的具体局限** | 本课题的增量 | 该增量为何以前做不到 |
|---|---|---|---|---|
| （真实引文，可核） | 一句话 | 见下方失效点分类 | 一句话 | 对应 §3 归因 |

### 失效点分类学（"深入分析"就落在这一列）

**别写"机制尚不清楚"**——那是把自己的懒惰安到别人头上。逐条指名道姓写成
**"这项工作在 ⟨条件⟩ 下失效，因为 ⟨机制⟩，故它无法回答 ⟨本课题的问题⟩"**。八类失配，对号入座：

| 失效类型 | 长什么样 | 写法示例（句式，非事实） |
|---|---|---|
| **人群失配** | 证据来自 X 人群，你的问题在 Y 人群，外推链断了 | "该队列 92% 为 ⟨A 人群⟩，而 ⟨B 人群⟩ 的 ⟨关键变量⟩ 分布显著不同，其阈值不能直接搬用" |
| **终点失配** | 用替代终点/复合终点，回答不了硬终点问题 | "以 ⟨替代指标⟩ 为主要终点，而临床要决策的是 ⟨硬终点⟩，二者在 ⟨条件⟩ 下已被证明解离" |
| **时间尺度失配** | 横断面证据回答不了动态问题 | "为单时点横断面测量，无法区分 ⟨因⟩ 与 ⟨果⟩，也测不到 ⟨动态过程⟩" |
| **机制层次失配** | 关联层面的证据，回答不了因果/机制问题 | "止步于相关性，未做 ⟨干预/敲除/孟德尔随机化⟩，无法排除 ⟨共同上游⟩ 的解释" |
| **测量失配** | 金标准不可及、测量误差吞掉效应 | "所用 ⟨测量法⟩ 的 LoA 达 ⟨范围⟩，宽于待检出的效应量，阴性结果不足以否定假说" |
| **设计失配** | 混杂控不住、选择偏倚、缺对照 | "回顾性单中心、无 ⟨关键协变量⟩，⟨适应证混杂⟩ 无法排除" |
| **规模失配** | 把握度不足，阴性≠不存在 | "n=⟨N⟩ 对 ⟨效应量⟩ 的把握度仅 ⟨%⟩，其阴性结论不能当作证据缺席" |
| **一致性断裂** | 多项高质量研究结论互斥且无人裁决 | "⟨研究1⟩ 与 ⟨研究2⟩ 结论相反，差异可能源于 ⟨设计差异⟩，领域至今未裁决" |

**规矩**：
- 局限必须**具体到设计参数**（人群构成、终点、样本量、测量精度、随访长度、机制层次），不接受"研究较少""不够深入""有待完善"。
- 局限来自你**真读过**的内容。只读了摘要就只写摘要撑得住的话，拿不准的标 `[待补充]`（照 AGENTS.md §五 判级铁律，这属 Minor，不阻断交付）。
- **别把别人的工作写成一无是处**——评审里很可能就坐着作者本人。正确姿势是"该工作在其设定下是成立的，但其设定排除了本课题关心的 ⟨条件⟩"。
- **这一列还有第二个用途**：写完后它要**整列回流**成你自己的风险清单（见 §5 第 4 段的"失效点回流"规则）。你指出的每一个坑，评审都会拿来问你怎么不掉进去。

## 3. gap 归因四选一：**这个空白为什么至今还在？**

这一问是整张卡的核心。答不出来，说明这个"空白"要么是假的（其实有人做了），要么是没价值的（大家都能做但不值得做）。
四选一，且**归因直接决定创新点类型和可行性怎么论**：

| 归因 | 判据 | 创新点应落在 | 可行性必须回答 |
|---|---|---|---|
| **① 技术不可及** | 问题早被提出，但缺测量/干预手段 | **方法使能**——你带来了此前不可及的观测或操控 | 这个技术你**真的可及吗**？前期数据、平台、已跑通的预实验（拿不出=空中楼阁） |
| **② 数据不可得** | 方法现成，缺样本/队列/随访 | **资源**——你能拿到别人拿不到的数据 | 伦理批件、样本量、合作协议、生物库准入（对应 `ethics-review.md`） |
| **③ 概念未提出** | 数据和技术都在，但没人这么想过 | **假说/视角**——最值钱也最容易被判"想当然" | **机制上的理由**（为什么这个假说合理）+ **可证伪的检验**，二者缺一必被质疑 |
| **④ 做过但证据互斥** | 高质量研究互相打架，无共识 | **裁决设计**——你的设计能判谁对 | 你的设计为何能裁决分歧，而**不是"再投一票"**（呼应 `novelty-check` 的"有争议"裁定） |

- 归因写进立项依据第 2 段末尾，一句话即可，但**必须出现**。
- 觉得"四个都沾一点"= 还没想清楚。挑主因，其余最多作补充。
- **归因 ① 而拿不出可及性证据 → 停下问用户**（照 AGENTS.md §六 给编号选项要前期数据），别硬写。

## 4. 关键科学问题：一句可证伪的命题

从 §2 的局限列 + §3 的归因**收敛**出来，不是另起炉灶想一句漂亮话。

**合格标准（四条全中）**：
1. **单句、单问题**——不是"明确 A、鉴定 B、评估 C"的并列分句。
2. **可证伪**——能说出"观察到什么就说明它错了"。
3. **不是宽泛愿景**——"探索 X 的机制""揭示 Y 的作用"这类扣分句式，评审已经看腻。
4. **能追溯**——它回答的正是 §2 表里某一条局限。

**放哪（按渠道）**：
- **NSFC 2026 新格式（面上/青年C）**：无独立栏 → 写进「研究内容」开头 + 摘要显著位置。
- **classic 类别（重点/青年A、B 等）**：有独立「拟解决的关键科学问题」栏 → 单列进去。
- **NIH**：Specific Aims 首段的 central hypothesis。
- **任务指标驱动渠道（重点研发、四大慢病重大专项）**：换成「待突破的关键技术瓶颈 + 对应考核指标」，别硬套科学问题句式。

⚠️ **凝练 ≠ 把没做的写成已做**：命题本身可以斩钉截铁，但支撑它的未核实前提（如"两组病理分期无差异"这类尚未做统计检验的断言）仍须标 `[待补充]`。

## 5. 立项依据五段骨架 + 笔墨预算

按顺序写这 5 段，**每段有规定动作和落点句**。百分比是**立项依据内部**的字数占比（不是全文）：

### 第 1 段 · 痛点事实（10–15%）
- **写**：当前在**哪个具体决策点**上卡住、只能采取什么次优做法、代价是什么（可量化）。
- **不写**："发病率逐年上升，严重威胁人类健康"——这句话对任何疾病都成立，因而对你的课题毫无信息量。
- **落点句**：「……因此临床在 ⟨决策点⟩ 上目前只能 ⟨次优做法⟩，代价是 ⟨可量化后果⟩。」
- **引用配额**：≤3 条（流行病学/指南各 1–2 条足矣）。

### 第 2 段 · 现有解法的失效分析（**35–40%，主体**）
- **写**：§2 对照表逐行展开成文字。每项工作一句"做了什么"+ 一到两句"在什么条件下失效、为什么"。段末给出 §3 的 gap 归因。
- **不写**："已有研究表明…然而机制尚不清楚"。
- **落点句**（每条工作都要有）：「……故该工作无法回答 ⟨本课题的问题⟩。」
- **引用配额**：全文 **≥60% 的引用集中在这一段**。这是判断稿子空不空的最硬指标。

### 第 3 段 · 关键科学问题（≤5%）
- 一句话（§4 的命题），单独成段，不要埋在论述里。
- **落点句**：「本项目拟回答：⟨可证伪命题⟩。」

### 第 4 段 · 切入点与假说（25–30%）
- **写**：你的假说是什么；**为什么它能绕开第 2 段列出的失效点**（机制上的理由）；据此可推出哪些可观测的预测。
- **不写**："本研究采用最新的 ⟨高新技术⟩"——技术本身不是切入点，除非它正是 §3 归因①里那个使能手段，且你要说明**它使能了什么此前不可及的观测**。
  （NSFC 医学部原话：避免无创新性思想而盲目追求使用高新技术和跟踪热点问题。）
- **落点句**：「若 ⟨机制假说⟩ 成立，则应观察到 ⟨可观测预测⟩；这正是上述工作因 ⟨失效点⟩ 无法触及的。」
- **引用配额**：只用于支撑假说的合理性与技术可及性（前期数据优先于文献）。
- ⚠️ **失效点必须回流成你自己的风险清单（盲评实测暴露的坑，别跳）**：
  你在第 2 段指出别人栽在哪，评审下一秒就会问"**你凭什么不栽在同一个地方**"。
  把对照表「具体局限」那一列**逐条**过一遍，对每条回答二选一——① 我的设计从结构上避开了它（说明怎么避）；
  ② 我避不开，所以把它写成风险并给缓解（协变量、分层、敏感性分析、预案）。
  **一条都不回应，等于自己给评审递了刀**：实测中一份稿子精准指出了"多中心设备差异 1.8 kPa"，
  转头自己设计三中心却零应对，可行性一维当场被扣分——而对照组因为接住了这条反而在该维反超。
  这一步同时防住骨架的固有副作用：**注意力被"论证得漂不漂亮"吸走，可行性与完整性反而变薄。**

### 第 5 段 · 价值锚（10%）
- **写**：假说成立会**改变哪个具体决策 / 推翻什么认知**，改变前后的状态各是什么。
- **不写**："具有重要的科学意义和应用价值""为临床提供理论依据""造福广大患者"。
- **落点句**：「本研究若成立，将使 ⟨具体决策或认知⟩ 从 ⟨现状⟩ 变为 ⟨改变后⟩。」

> **笔墨预算的意义**：不设预算时，第 2 段会退化成 5% 的"然而尚不清楚"，而背景铺陈膨胀到 60%——这就是空洞的字面成因。写完用 `scripts/hollowness_check.py --sections` 看实际分布。

## 6. 创新点的可证伪格式

**每条创新点五要素，缺一不成立**（写进渠道要求的"特色与创新"栏；NSFC 2026 新格式提炼进「研究内容」）：

```
创新点 N：⟨断言，一句话⟩
- 对照物：⟨最接近的现有工作 + 引文⟩ —— 它做到了 ⟨X⟩
- 增量类型：方法 ／ 人群 ／ 机制层次 ／ 尺度 ／ 裁决   （单选，别写"综合创新"）
- 为何以前做不到：⟨对应 §3 的 gap 归因⟩
- 可证伪的检验：若观察到 ⟨结果⟩，本创新点即被否定
- 若成立的后果：⟨改变什么决策或认知⟩
```

**硬规矩**：
- **对照物必须是别人的工作**。只找得到自己团队的工作作对照 → 这是 **new to me 不是 new to field**，降级写成"本团队首次将…"并如实说明领域内已有 ⟨X⟩。
- **无对照物时禁用这些词**：首次、填补空白、创新性地采用、国际领先、突破性、开创性。带上对照物和引文，这些词才有意义。
- 创新点**条数 2–3 条为宜**。列 5 条以上通常意味着每条都不够硬。
- 每条创新点都应能追溯到 §2 对照表的某一行——**追溯不到，说明它是凭空加的**。

## 7. 反模式对照表（照着改）

| 空洞写法 | 病灶 | 改成 |
|---|---|---|
| "XX 病发病率逐年上升，严重威胁人类健康" | 对任何疾病都成立 | 具体决策卡点 + 次优做法 + 可量化代价（§5 第 1 段） |
| "已有研究表明 A 与 B 相关，然而机制尚不清楚" | 把空白说成别人的疏忽 | 指名到具体研究 + 八类失效点之一（§2） |
| "本研究拟深入探讨…的机制，为临床提供理论依据" | 不可证伪 + 空价值 | 可证伪命题（§4）+ 具体决策改变（§5 第 5 段） |
| "本研究具有重要的科学意义和应用价值" | 零信息量 | 删掉，用第 5 段落点句代替 |
| "采用最新的单细胞测序/AI/多组学技术" | 技术≠创新 | 说明它使能了什么此前不可及的观测（§5 第 4 段） |
| "国内外尚无相关报道" | 通常是没查够 | 给检索证据（`novelty-check` 记录）或改口"据本次检索（式见附）未见…" |
| "填补了本领域的空白" | 无对照物的断言 | 创新点五要素（§6） |
| "结果将为后续研究奠定基础" | 把价值推给别人 | 本课题自己产出什么可用结论（§5 第 5 段） |

## 8. 缺用户输入时怎么办（别开放式追问，也别硬编）

深入分析吃两样用户独有的东西：**真实的临床观察**（他为什么觉得这里卡住）和**前期数据**（他凭什么能解决）。缺了照这么办：

1. **能枚举的用编号选项问**（照 AGENTS.md §六），例如：
   「你觉得这个空白至今还在，主因是哪一类？**1)** 缺测量/干预手段（技术不可及）**2)** 缺样本或随访数据 **3)** 没人这么设想过 **4)** 做过但结论互相打架。回一个数字即可。」
   ——比"请介绍一下你的研究背景"有用得多。
2. **纯事实项**（前期数据、预实验图、伦理批号、代表作）开放式要，缺则标 `[待补充]`。
3. **判级**：这类"待用户补"的项一律记 **Minor**，不阻断交付、不触发返工（AGENTS.md §五 判级铁律）。交付时列成「需你补的事实项」清单。
4. **绝不用编造填补**：编前期数据、编"最接近工作"、编检索结论，都踩不虚构红线。
