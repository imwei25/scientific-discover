# 迭代检索–批判循环（literature-review 与 deep-research 共用）

> 本文件是**共享引擎**：把"检索一次就写"升级成"回合制、缺口驱动、能自我批判"的多步循环。`literature-review`（领域综述）与 `deep-research`（单问题深挖）都引它；两者只在**产出契约**和**检索目标**上不同（见文末对照），循环本身一套。

## 为什么要多步
单步（拆式→检索一次→读摘要→写）的三个通病：①**覆盖不全**——第一次检索式没覆盖到的子面直接缺证据；②**证据等级停在偶然命中**——某论断只有一篇队列研究撑着，没人回去找 RCT/meta；③**矛盾被平滑掉**——相反结论各写一句、不并置核对。多步循环靠"缺口驱动的补检 + 停止判据 + 覆盖批判"解决这三点。

## 编排决策：并行还是串行（每次拆完子任务先自问一次）
1. **先判运行时能力**：当前框架能开**子代理**（任务派发/spawn 类工具）吗？"能并发调用工具"≠"能开子代理"。工具列表里没有子代理/任务类工具，或拿不准 → **一律串行**。
2. **再按复杂度分档**（借 Anthropic 编排经验，别过度并行）：
   - **简单**（1–2 个子面/子问题、来源少）→ 串行，主流程自己顺序查。
   - **中等**（3–4 个相对独立的子面/子问题）→ 并行：每个派一个子代理，独立上下文、明确目标与边界。
   - **复杂**（5+，或需大量抓取/多源交叉）→ 并行，主代理只综合。
   - **有依赖**（后一个要用前一个结论）→ 该段串行；无依赖部分才并行。
3. **并行铁律**：给每个子代理**明确目标、期望输出格式、来源类型、任务边界**（别只说"查 X"）；宁可少开几个也别为简单任务铺满子代理；子代理只回传**结论 + 来源（标题 + DOI/URL）**，主代理负责去重与综合。

## 回合制检索（核心）
把检索当**可重复调用的原语**（`literature-review/search.py` 走 Europe PMC，国内可达无门槛；有 claude.ai MCP/境外网络时可叠 `search-lit`），一回合一回合来：

**每回合**：
1. 对**当前证据薄弱的节点**（覆盖大纲里的子面 / 待答子问题）检索（按上面的编排决策决定并行/串行）。
2. 读入命中摘要，登记到证据表 / 台账。
3. **自评缺口**，据此生成**下一回合的检索式**（query expansion）：
   - 哪个节点**零证据 / 证据稀薄**？→ 换同义词、换概念组合、放宽/收紧年限补检。
   - 哪条关键论断**只靠单一来源或弱证据**？→ 针对该点去找更高等级证据（见下"证据等级爬升"）。
   - 出现的**新实体/新术语**（药名、标志物、量表）值得单独成一轮。

**证据等级爬升**（综述特有目标）：某论断现在只有队列/横断面支撑 → 主动检该点的 **RCT / 系统综述 / meta**。取证与写作按等级优先：**指南 / 系统综述 > RCT > 队列 > 病例对照 > 横断面 > 个案 > 临床前**；参考清单里给每条标等级。

**停止判据**（有判据 = 多步，无判据 = 退回单步）：满足任一即停该节点，别无限查——
- 每个节点在**相关证据等级上取到 ≥N 篇**（综述默认 N=3–5，视主题热度调）；**或**
- **连续两回合无新增**（同一批 DOI 反复命中，饱和）；**或**
- 达到预设**回合上限**（默认 3–4 轮）后转人工判断。

**检索日志**（可复现最低要求）：逐条记 `子面/子问题 | 回合 | 检索式 | 命中数 | 新增数 | 关键结论(标题+DOI)`，写 `outputs/search_log.md`。

## 交叉核实与矛盾
- **交叉核实**：关键论断看多个独立来源是否一致。
- **矛盾并置**：同一 (干预/暴露 → 结局) 上方向相反的，**并列呈现**、别只挑一个；判"真矛盾 vs 可调和（人群/剂量/时点/定义/校正不同）vs 证据分级可解"。综述走 `contradiction.py` + 台账做成矛盾矩阵；deep-research 至少在报告里并置分歧并标注。

## 覆盖批判者（成稿前一轮，借 Co-STORM moderator）
写之前（或初稿后）过一遍**批判者视角**，专挑没覆盖到的：
- **哪个子面/子问题零证据或只有弱证据？**
- **有没有该领域公认的重磅研究（大 RCT / 权威 meta / 指南）没被检到、没被引？**
- **哪条论断只有单来源？**
- **检索到但没用上的信息里，有没有反例/竞争假说被忽略？**
命中任一 → **触发一轮定向补检**（回到"回合制检索"），补齐再写。

## 反向核查（成稿前，借对抗思路）
挑 3–5 条最关键结论，**反过来用否定式/竞争假说去检索找反证**：扛得住反驳的才写成结论；扛不住的降级为"不确定"并入局限（deep-research 标为低置信度；综述写进"争议与空白"）。

## 两个技能的差异（循环相同，产出契约不同）
| | literature-review（升级版） | deep-research |
|---|---|---|
| 工作单元 | 一个**领域/主题**（求广覆盖） | 一个**具体问题**（求深核实） |
| 检索目标 | 覆盖领域 + **沿证据等级爬升** | 每子问题 2–4 个独立来源足以回答 |
| 组织轴 | 证据等级 / 主题 | 子问题 |
| 产出 | 结构化综述 + 证据分级 + 矛盾矩阵 + **可引用参考文献表**（喂 write-paper） | 问答报告 + **每条结论置信度** |
| 停止 | 每节各等级取够 / 两回合无新增 | 每子问题 2–4 源 / 两轮无新增 |

**共有**：编排决策、回合制检索、停止判据、覆盖批判、反向核查、不虚构、失败即上浮（某检索源失败先按降级路径换道，换道再失败才问用户）。
