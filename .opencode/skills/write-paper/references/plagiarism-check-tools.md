# 查重工具推荐

> 本文件从 SKILL.md「查重工具推荐」节搬出，由 SKILL.md 在成稿交付、向用户附查重建议时引用。

成稿交付时**主动**把下面的查重建议附给用户（**仅论文 / 投稿稿件适用**，标书、PPT、科普等不附）。这些均为网页端服务、需用户**自行上传**——正规学术查重没有免费 API，本技能**不代查、不上传用户稿件**：
- **中文稿**：
  - 免费初查（改稿期反复用）：**PaperPass**（paperpass.com）、**PaperYY**（paperyy.com），均有免费检测额度（以官网当期活动为准）。
  - 定稿权威（付费）：**知网 CNKI**——国内高校与期刊定稿判定的事实标准（个人查重入口 cx.cnki.net，按篇收费）；预算有限可先用**万方 / 维普**（约 3 元/千字）过渡，但最终以投稿对象实际使用的系统为准。
- **英文稿**：
  - 免费初查：**Scribbr 免费版**（scribbr.com，基于 Turnitin 数据库，免费版只提示有无重复、报告有限）、**Plagly**（plagly.com，免费网页比对）。
  - 定稿权威（付费）：**iThenticate**（ithenticate.com，Turnitin 旗下）——SCI 期刊 / 出版社收稿时跑的 Crossref Similarity Check 即此系统，按篇付费、个人可购。
- **两条提醒随清单一并告知用户**：① 上传时选**不收录 / 不入库**的选项，避免稿件先进比对库、正式投稿时反被判高重复；② 免费工具只做初筛，定稿前以权威系统（知网 / iThenticate）结果为准，重复率高的段落改写后再复查。
