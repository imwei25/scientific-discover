# 选刊策略（加权评分 + 三档梯队 + 掠夺性期刊核查）

> 本文件从 SKILL.md「先问清楚 · 目标期刊」节搬出，由 SKILL.md 在目标刊未定、需要帮用户选刊并拍板时引用。

- **选刊别拍脑袋，用加权评分 + 梯队策略**：候选刊按几维打分——**契合度(scope，权重最高)** > 读者匹配 > 影响因子/分区 > 周转速度 > 版面费(OA/APC) > 是否被 PubMed/SCI 收录，加权排序。定**三档梯队**(reach 冲刺 / target 主投 / safety 保底)，**投稿前就想好被拒后下一站**，省来回。**让用户拍板目标刊时照 AGENTS.md §六 编号呈现**：**1)** target 主投（推荐）　**2)** reach 冲刺　**3)** safety 保底，各附一句契合度/影响因子/周转说明，用户回一个数字即定目标刊往下走。⚠️ **掠夺性期刊核查**：查 DOAJ/COPE 会员、是否 PubMed 索引、编委与同行评议是否真实——承诺"几天录用"、乱收费、查无编辑流程的一律避开。
