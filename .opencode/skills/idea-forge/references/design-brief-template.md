# design_brief.md 模板（idea-forge 出件格式）

出件时按场景选变体；**所有变体共享的三节**（放文末）：
- **被否决的备选及理由**：对话中放弃的每个方向/方案 + 一句为什么（标书场景=答辩弹药，必留）。
- **遗留开放项**：没锻完的节点 + 当前倾向。
- **未核实断言清单（新增，必写）**：用户选择"不查、我认这条"的断言逐条列出，尤其"首次/没人做过/尚无报道"这类——**注明"未经检索核实，申报/投稿前须自查"**。一条都没有就写"无"，别省掉这一栏。
- **待补事实清单**：⏸ 节点汇总（伦理批号、数据明细等）——照判级铁律标注"Minor，不阻塞下游成文"。

每节内容都要**可追溯**：结论后面括号标它来自哪轮对话或哪条证据（如"（第 7 轮，DOI:10.xxxx）"），下游技能和用户都能对账。

## 变体 A · 标书（喂 grant-proposal 第 3.5 步，四件套一一映射）

```markdown
# 设计定案（标书）· <课题名>
> idea-forge 出件 <日期>；渠道：<渠道/类别>；对话 <N> 轮，证据 <M> 条

## 1. 立意卡
- 痛点：<哪个决策点卡住、现行次优做法、可量化代价>
- gap 归因：<四选一 + 依据>
- why-now：<现在多了什么>
- 关键科学问题（单句可证伪）：<……>
- 机制链条：<A→B→C→结局，逐环标 已证实/外推/推测（+证据）；最弱环及其着落>
- （指标驱动渠道）指南对表：<挂哪条方向/考核指标>

## 2. 创新点（2–3 条，五要素齐）
### 创新点 1：<断言>
对照物：<别人的工作+引文> ｜ 增量类型：<单选> ｜ 为何以前做不到：<对应 gap 归因> ｜ 检验：<什么结果算不成立> ｜ 若成立：<改变什么决策/认知>

## 3. 方案骨架
设计：<类型> ｜ 人群：<纳排要点> ｜ 干预/暴露：<……> ｜ 主要终点：<……+硬度判断>
样本量线索：<粗算结果或"需 clinical-stats 正式算">
Aim 依赖：<各 Aim 独立性判断 / Plan B>
研究基础咬合：<各 Aim 对应的自有基础；没有背书的 Aim 列进下面风险节，绝不虚构前期结果>
经费体量：<最大花钱项 vs 金额档位的匹配判断>
风险与缓解：<closest_work 失效点逐条回流 + 基础裸奔的 Aim + 机制链最弱环>

## 3.5 红队总攻记录
<每刀：攻击点（引台账哪条）→ 用户应答/出路选择；答不上的进「遗留开放项」——评审真问到时这就是预演底稿>

## 4. 证据台账 → closest_work.md
（同时落一份独立的 closest_work.md，五列：最接近工作(引文)|它回答了什么|具体局限|本课题增量|该增量为何以前做不到）
```

## 变体 B · 论文（喂 write-paper / nature-figure / literature-review）

```markdown
# 设计定案（论文故事线）· <暂定标题方向>
> idea-forge 出件 <日期>；对话 <N> 轮，证据 <M> 条

## 1. 故事线卡
- 核心主张（一句，含主张梯度级别）：<如"X 与 Y 独立相关（校正后）——不声称因果">
- 支撑数据点清单：<主张 → 统计输出哪一行，逐条>
- 惊喜点/故事核：<……或"平实证据补全型">

## 2. 定位
- 与最接近 3 篇的一句话差异：<……（引文）>
- 读者画像：<谁会引用>
- 目标刊三梯队：reach <刊> / target <刊>（推荐）/ safety <刊>，各附 scope 契合一句

## 3. 防御
- 局限清单（每条：局限 → 偏倚方向 → 缓解/降级）：<……>
- 反驳预演记录（审稿攻击 → 我方应答，直接喂讨论与 response letter）：<……>

## 4. 下游任务清单
- nature-figure 该画：<图清单，与主张一一对应>
- literature-review 该聚焦：<综述检索式建议>
```
