## 中断恢复

会话被压缩/中断后恢复：先 Read `forge_log.md`——议程、**检索档位**、节点状态、**阶段 0.5 摸底填掉的节点**、已答问题、证据台账都在里面；从第一个未闭合节点继续，**别把答过的问题再问一遍**，也**别把摸底已填的节点当空白重新 brainstorm**（这是对话式技能最败好感的行为）。

## 与其他技能的边界

- **topic-selection**：它管"做什么"（收敛漏斗到 PICO），本技能管"想清楚为什么值得做、凭什么是你、方案凭什么立得住"，假设方向已大致有了。它的"对抗式研究"是 agent 对文献单方面证伪；本技能的 grill 是 agent 拿着文献**和用户对话**。互补不互替。
- **deep-research**：它是本技能的**弹药库，不是流程步**——只在「深挖升级」节的三类承重墙节点＋「打磨已有」入口对表时按需调用，产物回填台账后对话照常。整题泛查、成体系报告是用户单独派 deep-research 的场景，别在锻打里替他跑。
- **peer-review / grant-proposal 评审模式**：只评不改的单向输出；本技能是与用户共决的双向对话。接力关系：评审报告里的方向性弱点（立意空、创新虚）正好构成本技能的现成议程。红队总攻（标书包分支 4）与 peer-review 的分工：总攻在**设计层**对着锻打台账开刀、与用户当场对答，peer-review 在**成稿后**对着全文评审；总攻不替代成稿评审。
- **grant-proposal / write-paper**：成文本体。本技能是它们的前置设计环节，产物经 `design_brief.md` 硬接口交付。
