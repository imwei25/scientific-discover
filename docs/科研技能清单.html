Research & Medical Agent

科研医学 Agent · 技能清单

覆盖从选题、检索、统计作图，到成稿、查引用、排版出件的科研全流程。每项技能按需触发，也可以串成流水线连续跑完一个完整目标。

22 项技能 5 个大类 本清单不含系统综述 / Meta 方法学模块

01

检索与文献

7 项
search-lit

医学文献精准检索与引用管理，覆盖 PubMed、Semantic Scholar、预印本三大源，含检索式构建、逐条 API 核实、BibTeX 导出全流程。

literature-review

叙述性文献综述智能撰写，覆盖主题测绘、缺口驱动的回合制检索、证据分级、跨文献矛盾扫描到成文与参考文献表全流程。

research-scan

科研方向全景摸底与背景调研，覆盖核心问题、主要流派、近年趋势、关键团队、争议焦点与可切入空白六个维度。

deep-research

单一具体问题的多源深度求证，覆盖多路检索、原文抓取、跨来源交叉核实到带引用、带置信度的结论报告全流程。

fulltext-retrieval

全文 PDF 批量获取与格式转换，覆盖 DOI / PMID / 标题解析、开放获取渠道、机构订阅通道到 PDF 转 Markdown 全流程。

zotero-library

本机 Zotero 文献库智能问答，覆盖文献库探测、分类导入、PDF 全文解析、语义检索到带页码引用的证据段输出。

reference-check

参考文献真实性核查与假引用识别，覆盖 DOI 验证、中英文标题比对、PubMed 核实与撤稿检测四道关口。

02

选题与立项

3 项
topic-selection

研究选题与科学假设生成，覆盖研究空白识别、候选课题发散、PICO 结构化到新颖性 / 可行性 / 价值 / 竞争度四维打分排序。

novelty-check

课题新颖性严格裁定与研究预注册，覆盖文献与试验注册库双重检索、新颖性分级判定到假设与主分析计划冻结。

grant-proposal

国自然 / 基金标书智能生成、润色与格式校验，覆盖立项依据到研究基础全章节，并含模拟评审打分。

03

数据、统计与作图

5 项
data-analysis

科研数据分析与统计建模，覆盖数据体检、描述统计、假设检验、回归 / 生存 / ROC / 方法比对到探索性可视化全流程。

clinical-stats

临床基线特征表与样本量测算，覆盖变量类型识别、组间检验选择、效应量与 SMD 计算到 Table 1 三线表输出。

nature-figure

投稿级科研图表制作，覆盖结论定义、配色与版式规范、森林图 / 生存曲线 / 火山图绘制到 300 dpi 与矢量格式导出。

deidentify

临床数据脱敏与去标识化，覆盖身份证、手机号、住院号、姓名、住址等敏感信息检测、一致性假名替换到人工复核提示全流程。

data-integrity

论文源数据数值完整性自查，覆盖复制粘贴痕迹、列间常数偏移、跨表复用、均值方差自洽等多类可疑模式筛查。

04

写作与评审

3 项
write-paper

原创研究论文全文撰写，覆盖标题、摘要、引言、方法、结果、讨论全章节，并含病例报告、投稿信与审稿意见回复。

humanize-academic

学术文本去 AI 味与润色，覆盖句式节奏重塑、AI 腔用词替换、中英文分别适配，术语、数据与引用零改动。

peer-review

论文与标书模拟评审，覆盖整体判断、方法与统计逐节剖析、报告规范核对到推荐意见，并含对抗红队攻击模式。

05

出件与识别

4 项
render-docx

稿件转 Word 投稿版排版，覆盖期刊格式预设、字体字号与页边距、双倍行距与连续行号到参考文献样式全套落参。

render-pdf-doc

学术文档转出版级 PDF，覆盖中英韩多语种排版、表格列宽自适应、中文学术字体到标书与简报成件输出。

ppt-master

文档与主题一键转演示文稿，覆盖素材解析、版式设计、SVG 页面生成到 PPTX 导出全流程。

ocr

图片与扫描件文字识别，覆盖网页截图、拍照表格、证件与图片版 PDF 多类输入，输出可编辑文本。

完整目标（从零到成稿）不必逐个点技能——直接说清目标，系统会按对应流水线依次调用并在每个质量闸汇报结果。
硬规矩：不虚构数据、结果、统计量、参考文献、伦理批号与注册号；缺的一律标「待补充」向你索要。
