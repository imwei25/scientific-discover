# 标书技能 评审能力改进 —— 调研与实测记录（2026-07）

> 记录 grant-proposal 技能从"纯合规"向"评审视角 + 内容质量"扩展的一轮工作：业界范式调研 → A/B 盲评实测 → 逐项去留。目的是让以后回顾"哪些评审范式试过、结果如何、为什么留/弃"，避免重复踩坑或重复造轮子。

## 一、动因

技能原本强在**合规层**（要求卡：结构提纲/字数硬限/格式/伦理/不虚构/AI 红线），弱在两处：
- **评审视角**：不判"该不该投这个渠道"、不知道"本渠道评审最看重什么"、不模拟评审怎么看。
- **内容质量/说服力**：重"格式齐不齐"，轻"话写得有没有说服力"。

## 二、调研：业界评审范式盘点（scout + 4 路深挖）

先派 1 个 scout 盘点四赛道，再对最有价值的目标并行深挖 4 路。要点：

| 赛道 | 代表 | 可吸收点 | 本轮是否采纳 |
|---|---|---|---|
| AI 技能生态 | borghei/Claude-Skills grants、K-Dense | funder-fit 七维弃标闸（读到 `funder_fit_scorer.py` 权重）、心智模型匹配、Heilmeier 就绪度闸、反模式评审心理 | ✅ 弃标闸/评价维/评审心理条 |
| 商业产品 | Granted AI Committee Review、Grant Hawk | 多 agent 角色化评审面板（隔离评→合议→共识排序）、按渠道配打分器 | ⏸ 未做（成本高，见 §六） |
| 学术范式 | NIH Specific Aims、Heilmeier、NSF Broader Impacts、Open Grants | 立意锁、对标已中标书校准 | ✅ 立意锁；❌ 对标已中（语料不可得，见 §六） |
| 评审/说服力 | NIH 三因子、Color Team(Pink/Red/Gold)、CARS、Gopen&Swan | 评审打分器、分阶段评审、引言结构、句级规则 | ✅ 三因子入 NIH 卡评价维；❌ CARS/句级（二档被否） |

## 三、实测协议：A/B 盲评

每项改造都用同一协议验证，不凭感觉：
1. **同一案例**：固定一个 NSFC 医学部 H 类胃癌案例（背景材料完整）。
2. **baseline vs treatment**：改造前 / 改造后各跑一版（同案例同材料，只差技能版本）。
3. **盲化**：去掉版本痕迹与技能术语泄露，随机标 A/B，评审不知道映射、不知道在测什么。
4. **3 个独立评审** 按国自然评审维度盲评打分 + 判优劣 + 指出具体差异。
5. **判定**：≥2/3 判 treatment 更强，**且优势落在该改造的目标维**（防止把 agent 临场发挥误记为方法之功）才算"有提升"；否则 `git` 回退。

### 4.1 一档（留）
- **弃标闸**（第 1.8 步）：硬闸一票否决（截止/资格/限项/受理范围）+ funder-fit 七维快评 + 三分区（≥11 起草 / ≤5 换渠道 / 中间问用户）。
- **评价维**：卡内"评审在乎什么"节，起草时按渠道最看重的维度分配笔墨。
- **评审心理条**：通用自查加"创新点分清领域没做过≠我没做过""主动写风险与缓解（回避风险显得天真）"。
- **归因**：3/3 判 B 更强，优势最集中在**风险论述**（三评审齐 A3→B5）和**创新增量表述**两维——正是新增两条评审心理条的直接效果，归因扎实。
- **白捡三条通用铁律**（盲评暴露的真实缺陷，随一档实装）：① 正文洁净度（禁技能名/方括号批注/自夸式元评论混入正文）；② 关键数字全文一致（摘要"6个月内"与正文"2年内"同组数据矛盾）。

### 4.2 二档（弃）
- 内容质量层全套：立意锁 + CARS 立项依据三段模板 + 句级检查 + 反空洞四问。
- **0/3 判 B 更强**（2 判 A 更强、1 判相当偏 B）。败因：
  - **CARS 三段被写成连续大段，削弱层次感**（评审对"连续叙事 vs 分节小标题"意见分裂——不是明确更优，只是换了种有争议的风格）。
  - 反空洞四问未生效（意义段反而更笼统；且"别写造福患者"一档评价维已覆盖，重复）。
  - 流程复杂化诱发**脚手架泄漏**（agent 把技能名方括号写进正文）。
- **教训**：CARS 一"碰正文结构"就崩。

### 4.3 立意锁单抽（留）
- 从二档只保留"起草前把关键科学问题凝练成 1 句可检验命题"，**明确"只帮想清+凝练问题、不规定正文其他段落结构写法"**，扔掉 CARS 和句级检查。
- **3/3 判 B 更强，目标维"科学问题凝练度"三评审整齐 A3→B5**（纯立意锁效果，可干净归因），且无二档那种结构维下滑。
- **配防护**（盲评暴露的立意锁副作用）：凝练命题时未核实前提仍标 `[待补充]`、创新点仍带"据本次检索"hedge——别为命题利落就把没做的统计写成已证实、个人首次说成领域首创。
- **关键经验**：立意锁成功正因为"只做一件事、不碰结构"；二档 CARS 失败正因为"碰了结构"。**最小、不侵入的改动最容易验证也最容易成功。**

### 4.4 评价维全覆盖 + 评审模式
- **评价维**从 2 张卡扩到全部 13 张渠道卡。有官方评分标准的直接引（NIH 三因子、博后 30/60/10、IIT 八要素、重点研发考核指标），据文体归纳的一律标注"(非官方评分表)"。3 张公共卡不加。
- **评审模式**（用户需求）：description 加评审触发，让"用户已有成稿、只想评审现有标书"也触发本技能；新增"评审模式"小节——按渠道评价维+评审心理+funder-fit 逐维审、按渠道评审语言给判（NIH 三因子 / 国自然优先-可-不予资助档）、每条弱点定位到段落给改法。边界：方法学/统计红队交 `peer-review`，本模式聚焦"作为标书评审会怎么看、能不能中"，只评不改。

## 五、关键经验（可复用到以后的改进）

1. **最小改动原则**：改动越不侵入正文结构，越容易验证、越容易成功。立意锁（不碰结构）留、二档 CARS（碰结构）弃，是同一原则的正反例。
2. **A/B 盲评拦住了会变差的实装**：二档听起来全是正经方法论（CARS/立意锁/句级检查），但盲评显示净效果为负。凭直觉直接上会把 CARS 层次崩坏和脚手架泄漏带进生产。
3. **严格归因防止把运气当方法**：判定要求"优势落在目标维"。立意锁的①科学问题凝练三评审一致 A3→B5 才算数；B 的引文更贴题、方案更聚焦（那次 agent 发挥）不计入立意锁之功。
4. **盲评白捡缺陷**：实测过程暴露的通用问题（脚手架泄漏、自夸式元评论、数字前后矛盾）都变成了铁律——实测不只判去留，还顺带发现 bug。
5. **诚实标注官方 vs 归纳**：评价维里官方评分标准直接引、据文体归纳的标"(非官方评分表)"，不冒充官方。

## 六、调研到但未采纳/受限（留给未来）

- **多 agent 角色化评审面板**（Granted Committee Review 式：6 角隔离评→合议→共识排序）：能力最大跃升，但要自研合议协议 + 多 agent 编排，且在按需容器+额度的部署环境里成本敏感。**未做**。若做，建议先轻量 2-3 角（领域+统计+怀疑者）单渠道试，用同样 A/B 盲评验证。
- **对标已中标书校准**：**受语料限制**——医学科研没有可批量抓取的中标申请书全文库（中文 kd.nsfc.cn 公开的是**结题报告**非申请书，申请书属保密件；英文只有 ~302 份杂领域 CC BY + FOIA 慢通道）。能落地的只有"摘要级基准（RePORTER 免费 API）+ 用户自带合规样本"，且须守合规护栏（只给自己打分、不进可复制文本位、接重合度红线）。**不做联网自动抓中标标书**（抓不到又踩抄袭线）。
- **分阶段 Pink/Red/Gold 闸**：可把线性流程升级为分完成度多镜头，但改动流程结构、增复杂度。暂缓，优先级低于"评审面板"。
- **fresh-eyes 低背景外审**：让干净上下文的子 agent 只读终稿、标"每处需读者猜逻辑的地方"——最划算，可做成 peer-review 的一个 mode。**候选，未做**。
