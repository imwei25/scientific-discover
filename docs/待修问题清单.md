## P1 — 唯一会造成不可恢复损失的

### 1. 备份没有异地，机器整体挂了备份跟着一起没
每天 3:30 备份、保留 7 天、确实在跑（当前 492 KB）——但它就躺在**同一块盘**上。盘坏 / 实例被删 / 误删，备份与数据一起消失。

- **怎么验**：`backup.sh:6` 自己就写着「异地容灾请再把 BACKUP_DIR 同步到别处（rsync / 对象存储）」——脚本作者明确把这步留给运维；服务器上 `ossutil` / `rclone` / `aws` **一个都没装**；也没有 `/etc/sci-backup.conf` 之类的独立配置（这条是吸取了告警那次教训后专门重查的）。
- **修**：`backup.sh` 末尾加一步传阿里云 OSS。**需要你给 bucket 与 AK**。
- **代价**：半小时 + OSS 费用（这点数据量几乎为零）。
- **还有**：备份从未做过**恢复演练**——没验证过的备份不算备份。这一步不需要你给任何东西，我随时能做。
