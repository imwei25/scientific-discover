# Niuma Science 界面预览稿 · 说明

这里的 4 个 HTML 是产品界面的**可运行快照**，给你做视觉美化用。

| 文件 | 是哪一屏 |
| --- | --- |
| `综述撰写-首屏表单.html` | 进入「综述撰写」模块看到的第一屏（欢迎区 + 立项表单 + 流程条） |
| `综述撰写-对话进行中.html` | 同一模块聊到一半：流程条走到第 3 步、文献卡片、产物下载卡 |
| `SCI论文-首屏表单.html` | 进入「SCI 论文」模块的第一屏（12 步流程里最复杂的一条） |
| `SCI论文-对话进行中.html` | 聊到一半：流程条走到第 4 步、表格 / 代码块 / 「下一步」表单卡 |

## 怎么用

**双击打开就行**，不用装任何东西、不用连服务器、不用登录。用 Chrome / Edge 打开效果最准。

页面是活的：会话栏能收起展开、左下角用户菜单能点开、模型下拉能点、表单能勾选、
侧栏产物能点预览。只有一件事做不了 —— **输入框发消息不会真的生成回答**（后面没接服务）。

## 改哪里

每个文件都是**单文件自包含**：HTML、CSS、JS、图标全在里面。

- 样式集中在文件顶部 `<style>…</style>` 那一整块（约 940 行），直接改就能看到效果。
- 文件最上面有一段被 `DEMO-BLOCK 开始 / 结束` 注释包住的脚本，那是**为了让文件能脱机打开临时加的**，
  不属于产品代码。改样式时不用管它，交回来时留着也没关系，我们会删掉。
- 除 DEMO-BLOCK 之外的部分与线上代码**逐字节一致**，所以你改的 CSS 我们能原样搬回去。

## 两点提醒

1. 页面里的**文献、病例、统计结果、期刊名全部是虚构的占位内容**，只为了把版式撑满，不是真实数据，别拿去引用。
2. 深浅色、字号、间距都可以改；但**流程条上的步骤名、表单里的字段文案先别动** —— 那些文字和后台逻辑是绑死的，
   要改文案我们另外走一遍。
