## P1 · 先给一个比喻：这套系统像「自家厨房 + 小区门禁」

**结论句**：干活的厨房在你家，我们只管门禁卡和水电表。

- **你家厨房（客户的电脑）**：所有食材（数据）、所有厨具（分析、作图、排版）都在你家，做菜（跑任务）也在你家。
- **小区门禁（我们的服务器）**：进出要刷卡（认人）、卡失效就进不去（停用）、水电有表（计量与限额）。
- 我们**认识每一个住户，但从不进你家门**。

**配图**：左「一户人家的厨房」+ 右「门禁岗亭 + 电表箱」，中间一条细线连着，线上标「只传对话内容」。

## P3 · 本地部署：一个安装包，双击就能用

**结论句**：不用装数据库、不用配环境、不用管理员权限。

- **一个 exe，双击安装**，装完桌面出现图标，点开就是聊天界面。
- **自带全套家伙什**（约 1.7 GB）：AI 引擎、20+ 项科研技能、Python 科学计算环境、文档转换工具——**客户机不需要预装任何东西**。
- **不用管理员权限**（装在当前用户目录下），IT 不用为每台机器开权限。
- **要求很低**：Win10/11 64 位 + 能上网。

**配图**：安装向导三步截图或图标条（下载 → 双击 → 打开即用）。

## P4 · 数据在哪：这是本方案最硬的卖点

**结论句**：患者数据不出你的电脑，不出你的单位。

- 上传的文件、聊天记录、生成的表格图片论文——**全部只存在这台电脑上**，服务器上一个字节都没有。
- 删除会话就是删本机文件，不需要跟我们打招呼。
- **必须同时讲清的一句话（合规口径，别回避）**：
  > 你**发给 AI 的那段文字**（问题、以及粘进去的内容）会经服务器转给模型厂商。
  > 所以含患者信息的数据，产品内置了「先脱敏再分析」的流程，请务必走它。

**配图**：一个「本机」框把文件、图表、论文都圈住；只有一条细线出去，线上是一个对话气泡。

## P5 · 本地能做什么：一台电脑装下一整条科研流水线

**结论句**：从找文献到出投稿稿，都在本地跑完。

| 组 | 干什么 |

| 算 | 统计分析、基线表、生存分析、数据脱敏 |
| 画 | 投稿级数据图、机制示意图 |

## P6 · 本地的两个「诚实提示」

**结论句**：有两件事要先说清楚，免得上线后当成故障。

1. **不能离线**：写论文靠的是云端大模型、查文献靠的是外网数据库。断网时界面能打开，但生成不了东西。
2. **两项进阶功能要额外装一次**（装完自动生效，一次性）：
   - 出版级 PDF 排版 → 需装 MiKTeX
   - PPT/Word 在线预览 → 需装 LibreOffice
   - 不装也不影响：Word 稿件照常出，PPT 照常生成，只是不能在界面里直接预览。

**配图**：两个小提示卡片，用「注意」而非「警告」的语气色。

## P7 · 云端只做三件事（对比页）

**结论句**：服务器不跑任务、不存数据，它退化成一个小门房。

| | 以前（全放服务器） | 现在（本地 + 瘦门房） |
|---|---|---|
| 谁出算力 | 服务器 | 客户自己的电脑 |
| 数据在哪 | 服务器上 | **客户本机** |
| 服务器压力 | 10 个人就要扩容 | 上千人都不吃力 |
| 服务器存什么 | 用户全部文件 | **只有「你是谁、用了多少」** |

云端保留的三件事：**① 认人 ② 放行 ③ 管人**（后三页各展开一件）。

**配图**：左右对比，左侧画得臃肿、右侧画得清爽。

## P8 · ① 认人：账号怎么发、通行证怎么用

**结论句**：管理员在后台建号，用户拿账号密码登录，之后免登录直到过期。

发号流程（四步图）：

1. 管理员在后台点「+ 新建账号」，填姓名、单位、职位、**档位**。
2. 页面**只显示这一次**初始密码 → 通过 OA/企微发给用户（我们库里只存加密指纹，看不到明文）。
3. 用户在客户端登录 → **强制改密** → 才拿到可用的通行证。
4. 之后免登录：通行证有效期 24 小时，快到期时程序自己悄悄续，用户完全无感（约 30 天不用重新输密码）。

**配图**：四步横向流程条；第 2 步旁边标一个「只显示一次」的红角标。

## P9 · ① 认人：停用是立刻生效的（这是商务抓手）

**结论句**：后台一点停用，这个人下一次说话就用不了了——不用等到期。

- **改档位 / 停用 / 重置密码 / 重置通行证** —— 任何一个动作，都会让这个人手里的通行证**当场作废**。
- 用户看到的不是一堆报错，而是一句人话：「账号信息已变更，请重新登录」「账号已停用，请联系管理员」。
- **只调额度不踢人**：额度是每次现查的，改完下一次请求就按新额度算，不打断正在干活的人。

**配图**：一个开关，拨下去的瞬间旁边的通行证变灰。

## P10 · ② 放行：为什么模型必须走我们这道门

**结论句**：模型的「钥匙」永远在服务器上，绝不发给客户端——这是计量能成立的前提。

用一句反问开场：**如果让客户端自己报「我用了多少」，会怎样？**

- 客户端在用户手里，等于让用户自己申报消费额 → 额度形同虚设。
- 所以：**所有模型调用必须经过我们的门房**，服务器读上游返回的真实用量入账。
- 顺带三个好处（都是客户直接受益的）：
  - **换模型、换供应商，用户无感**：后台加一家供应商就生效，客户端不用重装、不用重新登录。
  - **一家挂了自动换一家**：连不上、超时、被限流、**甚至上游余额欠费**，都会自动落到备用供应商。
  - **随时可停**：这就是续费与停用的开关。

**配图**：门房图标，手里一串钥匙，标注「钥匙不外发」。

## P11 · ② 放行：人多的时候会排队，而不是「没反应」

**结论句**：高峰期你会看到「正在排队，前面还有 3 个」，而不是莫名其妙没输出。

- 模型厂商对同时请求数有上限。十几个人同时跑长任务，撞上限的请求会被打回。
- 老做法的表现是「这一轮什么都没出来」——用户不知道发生了什么，于是**连点重发，越点越堵**。
- 现在：超出上限的请求在门房这里**按先来后到排队**，界面上明确显示排第几、大概还要多久。
- 一个人跑长任务**堵不死全场**（有单人并发上限）。

**配图**：银行叫号机的比喻图，屏幕上显示「前面还有 3 位」。

## P12 · ③ 管人：管理后台长什么样

**结论句**：所有运营动作在网页后台点鼠标完成，不需要登服务器敲命令。

- **找人**：按姓名任意一个字搜（姓氏优先），也能按单位、账号、手机号找。
- **筛人**：像 Excel 一样按档位、状态、今日用量、最近活跃筛。
- **成批改**：勾一批人，一次改档位 / 开通技能 / 停用恢复（一次最多 500 人，改前列出人名二次确认，事后逐人可查）。
- **发公告**：客户端顶栏有「公告」按钮和未读红点，**不弹窗打断人**，能往回翻半年。
- **看板**：谁在用、用了多少、当前排队情况。

**配图**：后台界面示意图（表格 + 筛选下拉 + 批量操作条），不用真实截图也可以画线框。

## P13 · 积分：把「$0.087」翻译成人话

**结论句**：后台记美元，用户看积分——因为没人算得清 $0.087 还剩几轮。

- **1 积分 = 1 美分**（可调，改了不影响真实额度，只影响显示的数字大小）。
- **两条线，各算各的，哪条先见底先挡**：**每日额度** + **每月额度**。
- **取整永远朝「用户不吃亏」的方向**：上限往下取、已用往上取。
  → 所以**绝不会出现「显示还剩 1 积分，一发消息就被拦」**。
- **显示在哪**：聊天页顶栏常驻「剩余积分 日 X · 月 Y」，每轮对话结束自动刷新，用掉 90% 变红。
- **上限填 0 = 不限**（内部账号用）。

**配图**：手机流量套餐/水电表的类比图 —— 两条进度条（日、月）。

## P14 · 档位：三档默认设置（可随时调）

**结论句**：档位决定三件事——每天多少积分、每月多少积分、能用哪些模型。

| 档位 | 每日 | 每月 | 说明 |
|---|---|---|---|
| 基础版 | 30 积分 | 500 积分 | 日常写作、查文献够用 |
| 专业版 | 150 积分 | 3000 积分 | 跑完整流水线（标书 / 论文 / 系统综述） |
| 内部 | 不限 | 不限 | 我们自己和演示用 |

- 生成插图**按张单独限**（默认每天 2 张）——因为一张图的成本比一轮对话高一两个量级。
- **额度用完会怎样**：请求在打给模型**之前**就被拦下（一分钱不会多花），界面上给的是整句人话：
  「今日积分已用尽（上限 30 积分），明日 0 点恢复」。
- **额度是运营参数，后台随时改，不用发新版本。**

**配图**：三张价签卡片，中间那张（专业版）做视觉突出。

## P15 · 用自己的 API 也行（给已有账号的客户）

**结论句**：客户自带模型账号时可以切过去，那部分不走我们的额度。

- 界面里可切换成「用我自己的 API」，弹窗顶部**始终显示当前走的是哪条路**。
- 走自己的 API 时请求根本不经过我们的服务器 → **不计入平台积分**（弹窗里明说了）。
- 一键「切回云端网关」，随时回到平台统一调度。

**配图**：一个二选一的开关，两条路各画一次。

## P16 · 更新与运维：用户要做的事很少

**结论句**：小改动在线更新，大版本覆盖安装，登录态和文件都不丢。

- **界面 / 技能的小更新**：后台一键发布，客户端提示一下、点一次刷新就生效，**不用重装**。
- **大版本**：直接运行新安装包**覆盖安装，不用先卸载**。登录态保留、产出与上传保留。
- **服务器侧（讲给 IT 听的一句话）**：全部状态收在一个目录里，每天凌晨自动备份并**真的恢复演练一次**，
  演练不通过就报警——「备份能不能恢复」不靠人记得去验。

**配图**：三级更新示意（在线小更新 / 覆盖安装 / 服务器自动备份）。

## P17 · 边界与风险：我们不夸大的三件事

**结论句**：这三条现在就说清楚，比上线后被问住强。

1. **技能明文在客户机上**。分级的商业价值靠「**额度 + 模型档次 + 随时可停**」兜底，
   **不承诺「低档用户在技术上无法使用高档功能」**。
2. **数据不出本地 ≠ 什么都不出去**。发给 AI 的文字要经服务器转给模型厂商（见 P4），
   含患者信息务必先走脱敏。
3. **版本会碎片化**。每台客户机各自升级，不像网页版一次全员生效——所以我们做了在线更新和公告。

**配图**：三个「诚实标签」卡片，用中性色，不要红色警告感。

## P18 · 一页总结

**结论句**：算力和数据在你手上，身份和账目在我们这里，两边各管各的一半。

| 谁 | 管什么 |
|---|---|
| **你的电脑** | 跑任务、存数据、谁能开这台机器 |
| **我们的服务器** | 你是谁、什么档位、用了多少、还能不能用 |

结尾一句：**云端认识每一个用户，但从不碰用户的内容。**

## 附：讲的时候容易被问到的问题（不做成页，放备注）

- **「断网能用吗？」** 不能生成内容，界面能开。
- **「我的病人数据会传走吗？」** 文件不会；你粘进对话框的文字会（转给模型厂商）。走脱敏流程。
- **「一个人能装几台机器？」** 同一账号多台机共用一份额度；要分机管控可一机一号。
- **「积分怎么充？」** 目前是管理员在后台按档位设额度，不是用户自助充值。
- **「服务器挂了怎么办？」** 本地界面和文件都在，只是生成不了；有每日备份 + 恢复演练。
- **「以前的网址打不开？」** 旧的免费域名在部分单位网被整片封了，已换成自有域名，升级即可。
