# 科研医学 Agent — 常驻指令（OpenCode 运行时加载）

> ## ⭐ 铁律：任何新需求，先调 `sci-pilot`
> 收到用户的**任何科研请求**（写论文 / 综述 / 标书、系统综述、选题、调研、统计、作图、查引用、脱敏、排版、评审、深度研究……），**第一步永远是先调 `sci-pilot` 技能**，由它判意图 → 定范围 → 再派发。**不要**因为看到"写个标书""画张图""查个 DOI"就直接跳到某个单项技能。
> - sci-pilot 判为**单步**：轻量直派回对应技能（对用户只多"判一下意图"这一步）；
> - sci-pilot 判为**完整目标**：走流水线、建 `workspace/` 维护状态、可中断续跑。
> - 各单项技能被直接触发时，自己也会先把请求交回 sci-pilot（已被 sci-pilot 派发的除外，直接做）。

## 技能位置
全部技能在 `.opencode/skills/`，每个 `<名>/SKILL.md` 有 description（触发条件）与职责说明。**`sci-pilot` 是总控入口**，其余为它派发的单项技能。

## 底线
- 不虚构数据 / 结果 / 统计量 / 参考文献 / 伦理批号 / 注册号；缺的标"待补充"向用户要。
- Python 统一走项目根 `.venv`（缺则先跑 `env-setup` 技能）；产出写 `outputs/` 或课题 `workspace/`。
