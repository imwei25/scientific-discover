# 0.1.44 发布说明

本版只做一件事：**把「直连自己的 API」这条路修顺**。用自己家 key 的用户，此前有两处每天都要撞一次的摩擦——
来回切换必须把 key 翻出来重粘；一套凭证只能挂一个模型，换模型不但要重填，还会把正在跑的任务连根拔掉。

## 一、凭证可以存在本机了（最多 3 套）

「模型 API 设置」里新增勾选框 **「把这套凭证保存在本机，下次切换不用重输」**，可以再写个备注名（如"我的 DeepSeek"）。

- **不勾就绝不落盘**——凭证要不要留在硬盘上是你自己的决定，不替你做主。
- 存下来之后，设置窗口顶部会列出这几套凭证（**只显示 key 的掩码**，如 `sk-a••••3456`），
  点一下「使用」当场切过去，**不用再输 key**。
- 最多 3 套；同一个 API 地址算同一套（改 key、加模型都是覆盖，不白占格子）。
  存第 4 套时会挤掉**最久没用过**的那套，并明确告诉你挤掉的是哪一个。
- 切回云端账号**不会**把存下来的凭证删掉——那正是这个功能要解决的事。

**顺带修的一处老摩擦**：API Key 留空 = 沿用本机已存的那把。
以前输入框写着"保存需重新粘贴"，你哪怕只是想加一个模型 ID，也得把 key 从某个记事本里翻出来重粘一遍。
（换成一个从没配过的新地址时仍会要求你填 key，不会拿别家的 key 去打。）

## 二、模型 ID 可以一次填多个，随时切换

模型 ID 输入框改成多行，**一行一个**（也可以用逗号分隔）：

```
deepseek-chat
deepseek-reasoner
```

- **第一个是默认模型**，其余出现在顶部「🧠 模型」菜单里，点一下就切。
- **同一套 key 内切换不重启后台**——以前切模型必须重启模型进程，跑了半小时的综述会被连根拔掉；
  现在这几个模型在保存时就一起登记好了，切换只是换个名字，正在跑的任务不受影响。
- 填了两个以上模型才会出现顶部的模型 pill（只有一个模型时没什么可切的，不占地方）。

## 安全与隐私

- 存下来的凭证只落在**这台电脑**上（`web/api-profiles.json`，仅当前用户可读），**不会上传到云端**，卸载随目录删除。
- 界面与接口**永远不回显完整 key**，只给掩码。
- 用存档切换时，地址同样要过内网地址护栏（与手填时同一条判据）。

## 升级方式

覆盖安装即可，配置与会话都保留。
