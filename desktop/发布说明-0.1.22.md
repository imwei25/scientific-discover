# 0.1.22 发布说明

> 这一版最大的变化：**你可以在微信 / 企业微信里直接使唤这个软件了**，还能让定时任务把结果推到你手机上。

## 这版有什么变化

### 1. 新功能：把软件接到微信 / 企业微信

在软件右上角点消息气泡图标「聊天接入」，跟着两步走，就能把某个对话接到你的**企业微信**或**个人微信**：

- **企业微信**：在企微管理后台建一个「智能机器人」，把 Bot ID 和 Secret 填进来即可（软件里有图文教程）。不需要公网、不需要配任何回调。
- **个人微信**：点「扫码绑定微信」，用手机微信扫一下就行，约 1 分钟。

绑好之后，在微信里像跟同事聊天一样给它发消息——查文献、跑统计、画图、写稿都能干，**生成的图片和文件直接发回你的聊天里**，电脑端的对话工作台也同步能看到。默认只有你自己能使唤它。

- 换个对话接入：回面板里选另一个会话再点保存，旧的自动脱开，凭证不用重填。
- 可以给聊天接入**单独选一个模型**，跟你电脑上界面用的模型互不影响。
- 手机上发 `/new` 换个话题、`/stop` 中断正在跑的任务。
- 前提：**这台电脑上的软件要开着**（可以最小化到托盘，见第 3 条）。

### 2. 定时任务可以把结果推到你的微信 / 企业微信

新建定时任务时，勾上「跑完把结果推送到我的微信/企业微信」，到点跑完后，它会把结果和产出的图表/文档直接发到你绑定的聊天里——人不在电脑前也能第一时间看到。

- 需要先配好第 1 条的「聊天接入」，且**软件保持开着**。软件关着时定时任务照常跑（产物留在会话里），只是推不了。

### 3. 点关闭按钮不再退出，而是缩到托盘

点窗口右上角的 ×，软件会**缩到右下角系统托盘**继续在后台运行，而不是直接退出——这样定时任务、聊天接入都能一直待命。

- 想唤回窗口：左键点一下托盘里的图标。
- 想彻底退出：**右键**托盘图标，选「完全关闭」。

### 4. 技能内容加密保护

软件里的科研技能现在以加密形式随包发布，安装目录里不再留可读的技能源码，运行时才在内存里还原、退出即清除。对使用没有任何影响，纯粹是内容保护。

## 升级注意

- 覆盖安装即可，**数据不会动**，老会话照常打开。
- 本版改到了后台程序和外壳，**必须装这个安装包**——只更新界面拿不到上面这些。
- 装之前请先退出正在运行的旧版（如果它缩在托盘里，右键「完全关闭」），否则安装程序覆盖不了正在使用的文件。
- 如果你上一版停在更早的版本，中间版本的内容也一并在这个包里，见
  [发布说明-0.1.21.md](发布说明-0.1.21.md)。
