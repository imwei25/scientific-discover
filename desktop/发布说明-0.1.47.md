# 0.1.47 发布说明

本版一件事：**企业版 coding plan 席位**——管理员把一份企业订阅的「地址 + key」分给少数 VIP 用户，
客户端拿到后**直连上游**，请求不再经过云端网关。

## 一、拿到席位后自动直连，什么都不用填

管理员在后台把席位分给你之后，客户端在**半分钟内**自动把凭证取回本机、把模型进程切成直连那家上游，
并弹一句提示（顶部 🧠 模型菜单里的清单也换成这份席位的模型）。正在跑任务时不会打断——等这一轮跑完再切。

- 凭证存在本机（`web/api-profiles.json`，与你自己保存的直连凭证同一个文件），**不占**你自己那 3 套的名额，也不会被挤掉。
- 直连期间**不计平台积分**；你在云端网关那边只保留基础档一半的积分作应急兜底（账号面板里能看到）。
- 上游报错时的提示会直接说明「你正走席位直连」，该找管理员核对席位还是切回网关，一句话说清。

## 二、随时切回网关、再切回席位

在对话框输入 `api-config` 打开「模型 API 设置」：

- 顶部会写明「当前：企业版 coding plan 席位」；左下「切回云端账号」= 暂停直连，回到平台统一调度。
  切回之后**不会再被自动推回**席位——尊重你的选择。
- 凭证列表里那张带「coding plan 席位 · 管理员分配」标签的卡片，点「使用」即切回直连。
- 这张卡**不能在本机删除**（删了下次同步又会回来）；不想用就切回云端，要彻底收回请找管理员。
- 锁屏后解锁、同账号重新登录都不改变你当前走的路。退出登录会把席位凭证从本机清掉。

## 三、管理员这边

后台新增「席位」页：新增 / 编辑 / 拉模型列表 / 测试连通 / 分配 / 释放 / 删除；「用户」页每个人的「…」里也能直接分配或释放。
分配、收回、换 key 都**不踢人下线**：客户端靠 30 秒一次的额度轮询自己发现并处理——收回后半分钟内自动切回网关并删掉本机凭证。

## 升级方式

服务端要先更新到含 `feat(seats)` 的版本（席位接口与额度规则都在服务端）。客户端改了 `web/server.mjs`
与 `web/cloud-account.mjs`，**界面包不够，要装本安装器**。
