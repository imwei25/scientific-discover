# 0.1.16 发布说明

> 0.1.14 / 0.1.15 都没有发出去过（打包配置有问题，安装包压根没打出来），它们的内容全在这一版里。

## 这版有什么变化

### 1. 子目录里的产出终于看得见了，还能一键打包全部下载

以前右侧「本轮产出」只列最外面那一层文件。文献全文、分组的图、审查报告这些放在子文件夹里的
产出，只会在列表末尾换来一句话：**「另有 N 个文件在更深的子目录里，让助手把它们移到一层目录
就会出现」**。

这句话对着屏幕的人几乎没法执行——你看不到文件夹，也不知道"让助手移文件"该怎么说，读起来就是
"我的东西丢了，还得去求 AI 才能拿回来"。

现在：

- **子文件夹按目录分组显示，默认收起**，点一下展开。`pdfs/` 那一堆文献全文仍旧显示成
  「已下载文献全文 N 篇」，不会把成稿淹掉。
- 折叠块里的每个文件都能**预览和下载**（以前那一堆只能下载）。
- 顶上多了一颗 **「打包下载」**：把这个会话的**全部**产出打成一个 zip，文件夹结构原样保留，
  一次拿走。文件特别多或特别大时（超过 200MB）会明确告诉你，让你在列表里挑着下。

> 病人对照表那类含真实姓名的文件，**列表里不显示、打包里也不会有**，与之前一致。

### 2. 断线之后给「继续」，不再让你白跑一遍

以前网络断一下，界面会说"连接中断了，后台这一轮也已经结束，点「重新生成」可以再来一次"——
可它自己都说了后台已经跑完，结果就在服务器上。按它说的重跑，等于让一份已经做好的 PPT 再花
十分钟、再烧一次额度。

现在这种情况给的是**「继续」**：直接把那一轮的回复和产出取回来。取不回来才会把「重新生成」
交还给你（不会假装成功）。

### 3. 润色 Word 稿：只改字，你的排版一个字节都不动，改动落成 Word 修订

以前给 Word 稿润色，走的是「转成 Markdown → 改写 → **重新生成**一份 Word」。问题不在"格式没调好"，
而在**重新生成**：原文件里 Markdown 表达不了的东西会全部消失，而且一路不报错——

- **EndNote / Zotero 的引文域变成死文本**，你回 Word 再也没法更新文献表；
- **合并单元格的表头被拍平**（Markdown 的表格语法里根本没有"跨行跨列"这回事）；
- 页眉页脚、分节、页码、交叉引用、题注自动编号、批注、合作者的修订痕迹，一并丢失。

现在改成**就地改写**：只动被改的那几个字，文件里其余部分逐字节原样保留。所以上面这些东西
**不是"尽量保住"，而是根本没被碰过**。图和表同理——它们从没离开过你的文件。

改动默认落成 **Word 原生修订**：打开「审阅」就能逐条看它改了什么、逐条接受或拒绝，
不同意的当场否掉。要干净稿就点「全部接受」。

> 两点如实说明：
> - 一句话里如果有单独变了颜色或加粗的词，而改写正好跨过那个边界，被合并进来的文字会跟着
>   前一段的格式走。遇到这种情况助手会**主动告诉你是哪一处**，不会闷着。
> - `.pdf` / `.md` 稿件没有可回填的排版，仍走原来那条路（转 Markdown 再排版出件）。

### 4. 稿件翻译：排版不动

Word 稿件的翻译改成和润色同一套"就地改写"的机制：段落样式、缩进、编号、表格、图片位置分毫不动，
译文落在该段的主导格式上。另外会自动标好译文的语言、换上西文字体——否则 Word 会拿原语言的词典
去校对译文（全篇红波浪线），英文也会用中文字体渲染，一看就是机翻。

段内局部格式（某个词单独加粗之类）会被统一成整段格式，这一点机器判断不了落在哪儿，助手会逐段
告诉你。

### 4. 图片识字（OCR）：云端不可用时自动改用 Windows 自带的识别

云端识字接口偶尔会因为服务器版本没跟上而不可用。以前遇到这种情况只甩一句「HTTP 404」，既没说
是服务器的事，也没有退路。现在会**自动换用 Windows 系统自带的离线识别**继续干活，并告诉你换了
哪条通道、为什么。额度用尽时同样自动换道。

> 系统自带的这条通道免费不限次，但**不做表格版面、不认 PDF、错字率更高**（实测把 `58.00` 认成
> `58 · 00`）。用它出的结果，关键数字请人工核一遍。

### 5. 润色/翻译出来的 Word 稿在面板里满屏乱码

润色和翻译现在直接改写你的 Word 文件（排版不动），而阅读器面板还按纯文本去读它——一份 501KB
的 .docx 被整篇当文字塞进正文，看到的就是满屏方块和乱码，第一反应是"它把我的稿子写坏了"。
其实文件本身一直是好的，坏的只是那一屏预览。

现在面板改成用和「预览」按钮同一套渲染（服务端把 docx 转成网页再嵌进来），转换失败会明说
而不是把一框英文报错当成正文。

> 这个预览显示的是**接受全部修订之后**的样子，被删掉的原文在预览里看不见——要看修改痕迹，
> 请下载后在 Word 里打开。

## 升级注意

- 覆盖安装即可，**数据不会动**，老会话照常打开。
- 本版改到了后台程序，**必须装这个安装包**——只更新界面拿不到上面这些。
