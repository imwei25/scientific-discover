# 0.1.20 发布说明

## 这版有什么变化

### 1. 会话可以指定「工作目录」，同一个目录的会话自动归到一起

新建对话之后、**发第一条消息之前**，输入框下方多了一个「工作目录」按钮。点它可以挑你电脑上
的任意一个文件夹（比如 `D:\论文\甲状腺课题`）。挑定之后：

- 这次对话里 AI 读写的文件、做出来的图表和稿件，**直接落在那个文件夹里**，不再藏在软件自己
  的目录下——你用资源管理器就能打开，也方便直接放进你原有的课题文件夹结构里。
- 用**同一个目录**的多次对话，会在左侧自动归到同一个「文件夹」分组下。

两件要留意的事：

- **只能在对话开始前定。** 一旦发了消息或传了文件，工作目录就固定下来了，改不了（这是底层
  的硬限制，不是没做）。要换目录请新建一个对话再选。
- **删除会话不会删那个目录里的任何文件。** 那是你自己的文件夹，我们只删对话记录和你上传到
  这次会话里的原始文件；确认框上也会把这句话写清楚。

### 2. 左侧会话栏：「项目」和「文件夹」两个分类，都可以折叠

左侧现在是三段：**项目**、**文件夹**、**最近会话**。前两个默认是收起的，点一下展开。

- 一个会话可以**同时**属于某个项目和某个文件夹，两边都会列出它。
- 「项目」还是你自己建、自己拖进去的；「文件夹」是按上面那个工作目录自动分的。
- 拖着一个会话在收起的分类上停一下，它会自动展开，不用先松手再点开。

### 3. 会话可以拖着改顺序，「置顶」去掉了

以前只有「置顶」一个档位，现在可以**直接把任意一条会话拖到你想要的位置**——从最后一条拖到
第一条也行。项目里、文件夹里、最近会话里各自记各自的顺序，互不干扰。

因为拖动已经能做到"排到最前"，原来的「置顶」按钮就一并去掉了。以前置顶过的会话不会丢，
只是回到普通列表里，你可以把它拖到你想要的位置。

### 4. 流程条：六类「显示的和实际做的对不上」一次修净

结构化流程（综述 / 论文 / 标书等）顶部那条步骤条，此前会在若干情形下显示错误——比如某一步
明明重做过却仍显示旧结论、并行的分支被误判成一起作废、归因标错步骤等。这一轮把状态判定整个
重做了一遍，并用模拟真实用户的测试跑过。

## 升级注意

- 覆盖安装即可，**数据不会动**，老会话照常打开。
- 本版改到了后台程序，**必须装这个安装包**——只更新界面拿不到上面这些。
- 装之前请先退出正在运行的旧版，否则安装程序覆盖不了正在使用的文件。
- 如果你上一版停在 0.1.18 或更早，中间版本的内容也一并在这个包里，见
  [发布说明-0.1.19.md](发布说明-0.1.19.md)。
