# 0.1.51 发布说明

本版只做一件事：**在学校、医院的网络里，把你们单位订了的文献真正下下来**，并把下到的
PDF 连同题录一起存进 Zotero。

## 一、机构订阅的全文，现在能下了

以前软件只能下「开放获取（OA）」的文献——就是任何人都能免费看的那一类。你们单位花钱订了的
那些（大量临床与基础研究的正刊文章都在这里），以前一律下不到，只能列进「需要人工获取」的清单。

本版起，**只要这台电脑在学校 / 医院的网络里**（或者你在浏览器里登过学校图书馆 / CARSI），
软件就能用你们单位本来就有的订阅权限，把这些全文取下来。用的是你自己的正当权限，
不是绕过付费墙。

### 你需要做什么？多数情况下：什么都不用做

软件会在需要的时候自己弹出一个浏览器窗口。**关于这个窗口，有两件事要知道：**

1. **它是一个独立的浏览器，和你平时用的 Chrome 互不影响**，所以看不到你的收藏夹和登录状态。
   这不是我们的选择——新版 Chrome 不允许程序连接你日常那个浏览器，绕不过去。
2. **学校 / 医院是按 IP 授权的（也就是你人在单位网里）：不用登录任何东西**，直接就能下。
   **如果你们是用 CARSI / 图书馆账号的**：在这个新窗口里登录一次，以后一直记着，不用反复登。

窗口开着别关，下载期间它要用。

### 下不到的时候，会明确告诉你是哪一种下不到

这一点很重要——四种情况的应对完全不同，软件会分开说：

| 提示 | 意思 | 你该做什么 |
|---|---|---|
| 本机构未订购 | 你们单位确实没买这篇 | 走馆际互借，或找作者要 |
| 需要人机验证 | 出版商弹了「我不是机器人」 | 去那个浏览器窗口点一下，再下一次。**软件绝不会替你点验证码** |
| 需要登录 | 这家出版商不认 IP，要账号 | 在那个窗口登录一次再重试 |
| 页面上找不到全文链接 | 该出版商的页面结构特殊 | 手动去下，或换馆际互借 |

### 还有一点提速

即便不开浏览器，常规下载本身也改得更像真人访问了，所以在单位网络里，**一部分订阅文献
在第一步就能直接下到**，根本用不着走上面那个流程。

### 说清楚做不到的

- 单位**没订**的文献，两条路都下不到——这是设计如此，不是故障。
- 为防止触发出版商的批量下载风控（真会连累整个单位的访问权限），这条通道**刻意限量限速**：
  一次最多 20 篇、每篇之间隔几秒。篇数多就分几次跑。
- 各家出版商的成功率还没有在真实的学校网络里做过统计。遇到下不到的，按上表对号入座即可。

## 二、下到的 PDF，能连题录一起存进 Zotero 了

以前「导出到 Zotero」只写进去一条题录，PDF 还得你自己再找一遍。现在软件会把**刚下到的
全文自动挂到对应的那条文献下面**，在 Zotero 里点开就能看，全文检索也能搜到。

- 汇报时会分开说「进库几条」和「其中几条带全文」——**这两个数往往不一样**，不带全文的会
  告诉你原因。
- 同一批重复导出不会在库里产生重复条目，可以放心重试。

## 三、下不到东西时，先让软件自查

跟助手说「做个机构网络自检」，它会跑一遍并给你一份报告（约两三分钟）。报告直接回答
四个问题：这台机器到底在哪张网里、网络本身通不通、每家出版商分别卡在哪一步、浏览器
起来没有。

这份报告的用处在于：**「下不到」至少有五种完全不同的原因**，自己看是看不出来的——
可能是没在单位网里（连了 VPN 或访客 WiFi）、可能是网络根本不通、可能是单位真没订、
可能是卡在人机验证、也可能是那家出版商页面特殊。报告会逐条说清是哪一种，以及该怎么办。

注意：**报告里包含这台机器的出口 IP 和网络归属**（这正是用来判断你在不在单位网里的
依据）。软件跑之前会提示你，发给别人之前自己确认一下。

## 四、修掉的问题

- Windows 下某些提示信息会让下载脚本直接崩掉（命令行编码问题），现已修复。
- 出版商弹人机验证时，以前会被误报成「需要登录」，把人引去登录学校账号——方向完全错了，
  现在会如实说是人机验证。
