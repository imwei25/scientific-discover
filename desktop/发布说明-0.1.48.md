# 0.1.48 发布说明

本版是 0.1.47 的正式对外版：功能与 0.1.47 相同（0.1.47 只在内部发放），外加一处显示口径修正。

## 一、企业版 coding plan 席位（自 0.1.47）

管理员把一份企业订阅的「地址 + key」分给少数 VIP 用户后，客户端**半分钟内**自动取回凭证、把模型进程切成直连那家上游，
请求不再经过云端网关。正在跑的任务不会被打断，等这一轮跑完再切。

- 凭证存在本机（`web/api-profiles.json`），不占你自己那 3 套直连凭证的名额。
- 直连期间**不计平台积分**；云端网关那边只保留基础档一半的积分作应急。
- 在对话框输入 `api-config`：顶部会写明「当前：企业版 coding plan 席位」；左下「切回云端账号」暂停直连，
  凭证列表里带「coding plan 席位 · 管理员分配」标签的那张卡点「使用」即切回直连。这张卡不能在本机删除，要彻底收回请找管理员。
- 管理员收回或换 key 都不踢人下线，客户端半分钟内自行发现并处理。

## 二、金额单位统一为人民币

账户菜单与额度提示里「1 积分 = $0.01」的美元写法改成「¥」，与后台口径一致。积分数量、扣减规则不变。

## 升级方式

服务端须先更新到含席位接口的版本。客户端改了 `web/server.mjs` 与 `web/cloud-account.mjs`，**界面包不够，要装本安装器**。
