# 0.1.23 发布说明

> 这一版把「聊天接入」做成了**微信、企业微信可以同时用、各接各的会话**，还修了几个体验问题。

## 这版有什么变化

### 1. 微信和企业微信可以同时接入，各接各的会话

以前只能二选一。现在「聊天接入」面板做成了**两个标签页**：企业微信一页、微信一页，
**各自绑各自的会话，互不影响**。比如企业微信接到「项目A」、微信接到「项目B」，两边同时在线。

- 企业微信页：填 Bot ID / Secret → 选会话 → 点「保存并连接」一步搞定。
- 微信页：扫码绑定 → 选会话 → 点「绑定到该会话」。
- 每个平台可以单独换绑、单独断开，凭证保留不用重填。

### 2. 聊天里的对话会自动归到对应的文件夹、挂上标记图标

微信/企微里每次对话，其实是在你绑定会话的**工作目录**里新开一段。以前这些新会话散落在
「最近会话」里、也看不出跟聊天的关系。现在：

- 这些会话会**自动归到绑定会话所在的文件夹**；
- 会话列表里给它们挂上**微信（绿）/企业微信（蓝）图标**，一眼看出哪些通着聊天。

### 3. 会话下拉默认选中你正在看的会话

打开聊天接入面板时，会话下拉默认就是你**当前正在看的那个会话**，省得每次翻找——最常见的
操作就是「把眼前这个接进去」。

### 4. 模型报错时给人话提示

聊天里如果碰到模型服务临时故障，不再是一句看不懂的英文，而是「模型服务暂时不可用，换个
模型或过一会儿再试」，并带一个编号供技术支持排查。

## 升级注意

- 覆盖安装即可，**数据不会动**，老会话照常打开；已配置的聊天接入凭证跨升级保留。
- 本版改到了后台程序，**必须装这个安装包**——只更新界面拿不到上面这些（尤其是多平台同时接入）。
- 装之前请先退出正在运行的旧版（若缩在托盘里，右键「完全关闭」），否则覆盖不了正在使用的文件。
- 更早版本的内容也一并在这个包里，见 [发布说明-0.1.22.md](发布说明-0.1.22.md)。
