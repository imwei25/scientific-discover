# 桌面版 0.1.10 发布说明（2026-08-07）

## 这一版改了什么

**只改了对话页中间那一栏的样子和「基金申报」的表单，左侧会话栏、右侧上传 / Zotero、
顶栏图标与字样一律没动。** 生成能力、技能、模型接入都不变。

### 1. 流程条改成横向单行

原来是一排会折行的胶囊，一条 12 步的流程会折成三行、把对话区顶掉小半屏。
现在是**编号圆圈 + 步骤名 + 一行副标题**，连接线串成一排：

- 一眼看得出「一共几步、现在第几步、这一步是干什么的」
- 看不全就**横向滚**：鼠标滚轮直接滚（滚到头会把滚动交回页面，不会卡住整页）、
  滚动条常驻可见、左右还有内容时那一侧会浮一层渐隐
- **打开页面自动把当前步摆到视野中间**，不用自己拖过去
- 鼠标移到任意一格，弹出这一步的完整说明（副标题被省略号截断、或步骤太多被收起时，
  全文都在这里）

### 2. 补上「基础信息录入」作为流程第 1 步

填表本来就是流程的第一步，而原来的流程条是从第二步起数的 —— 用户正在做第一步，
界面却显示"还没开始"。补上之后「填完点开始 → 进入第 2 步」才对得上。

配套改动：**进入模块的第一屏不再显示底部输入框**，那一屏要做的事只有一件 ——
把表填完点「开始」。点了「开始」（或「跳过表单，直接打字」）输入框就回来。
「自由对话」不受影响，输入框始终在。

### 3. 表单改成区块化的两列布局

原来是一列到底的长表单。现在按内容切成若干张**区块卡**（图标 + 一句话说明 +
「区块 N / M」角标），字段排两列，窄屏自动回落一列。

- 说明文字改回**常驻可见**（原来收在「?」里，触屏上根本点不出来）
- 非必填项明确标「选填」，不再只能靠"有没有星号"反推
- 底部换成「**必填完成度 X% · 已完成 N / M 项**」，一眼知道还剩多少
- 点提交时缺项**就地标红并滚到第一个**，不再只在底部列一串名字让你自己回去找

### 4.「基金申报」模块的表单与流程按新方案重排

流程六格：**基础信息录入 › 研究方向生成 › 选题遴选确认 › 标书初稿生成 ›
评审自查校验 › 标书最终成稿**。

- 原来的「选题收敛」与「新颖性裁定与预注册」并成一格「选题遴选确认」——
  这两步本来就是一件事的两半：先列候选、再判这个题还新不新，判不过就换一个重来。
  **它仍然是质量闸**：新颖性不过会退回「研究方向生成」重挑，不会硬着头皮往下写。
- 表单换成三个区块：**项目基本信息**（申请类型 / 项目关键字 / 领域分类 / 申请金额 /
  研究起止年）、**申请人信息**（姓名 / 职称 / 依托单位 / 邮箱 / 电话）、
  **撰写要求与工作基础**（撰写要求 / 工作基础 / 材料上传）。
- 项目关键字是新的标签输入：敲完回车即成一个标签，也可以一次粘一串用逗号分隔。
- 材料上传改成拖拽区 + 文件卡列表，点一下选中即随任务交给 AI。

**隐私**：联系邮箱与手机号**只留在本机表单里，不会随任务发给模型** —— 写标书用不到
它们。表单上也标了这句话。

## 用户怎么升

直接运行新安装包覆盖安装即可，**不用先卸载**。

- 登录态保留（`cloud-state.json` 跨升级不动），装完不用重新登录
- 产出与上传保留（`outputs\` / `uploads\`）
- 在线更新过的技能包 / 界面包会被重置成本安装包自带的版本（装完可再从服务器拉最新）

## 为什么这次必须发安装包，不能走「界面包」

本次除了 `web/index.html`，还改了 `web/workflows.mjs`（模块流程与表单的定义）。
**界面包按设计一律拒收 `.mjs`** —— 那是本机网关的服务端代码，换它要重启网关，
坏了客户端起不来（服务端发布闸与客户端安装器两道都拦）。

只发 HTML 那一半会得到一个自相矛盾的界面：新的渲染器配旧的表单定义，
「基金申报」还是老的七格流程、没有关键字输入框。所以这一版走安装包。

## 已知取舍

- **12 步以上的流程（SCI 论文）横向装不下**，需要滚动。已经自动收掉副标题把宽度让给
  步骤名，并且进页面就把当前步摆到中间，但整条仍然看不全 —— 步骤数摆在那里。
- **「申请类型」没有预先选中**「面上项目」。它决定整篇标书的结构与逐节字数硬限，
  按错版本整篇作废，所以不替用户默认，必须自己点一下。
