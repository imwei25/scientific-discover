# 0.1.19 发布说明

## 这版有什么变化

### 1. 定时任务：关掉软件，到点它自己跑

新增「定时任务」：设一次，比如「每周一早上 7 点扫一遍新文献」，到点由 Windows 的任务计划
把它拉起来跑完整一轮，产物落进一个新会话，下次你打开软件时会提示你去看。

- **软件关着照跑**；但机器关机或睡眠时不跑（开机后会尽快补跑一次），注销或切换 Windows
  账户时也不跑。
- 跑的时候没人在旁边，遇到要拍板的地方它会自己选推荐项——**产物请过目再用**。
- 你可以给自己留一条保护线（「剩余积分低于多少就不跑」），免得一个跑飞的任务把当天额度吃光。
- 这个功能按账号档位放开：有的档位只能用内置模板（如「文献推送」），有的可以自由写指令。
  看不到入口就是当前档位没开。
- 卸载软件时会一并撤掉已注册的计划任务。

### 2. 自动推进：只要一张图，做完就停

勾了「自动推进」之后，**只画一张图这种单步任务，也会在做完之后被反复推进好几次**——
它给已经交付好的东西继续加工（改配色、再出一版），直到撞上轮数上限才停。

原因是收敛完全靠 AI 自己在结尾打一个「我做完了」的标记，而单步任务它常常忘了打，系统就
当它还没做完。现在两头都补上了：AI 被明确告知单步产物做完当轮就打标记；万一还是漏了，
系统看到**连续两轮只说话、没再动手做任何事**，就判定已经做完并停下来。

### 3. 标书 / 论文：先把立意锻打硬，再去查它新不新

新增【立意锻打】——多轮对话把你的立意、创新点、方案（标书）或故事线、主张、目标刊（论文）
问到硬为止：空白的地方先检索再给带出处的候选，没验证的主张先检索再拷问，最后出一份设计定案，
直接喂给后面的写作步骤。

同时把标书和论文的流程顺序改成**「先锻打、后裁定」**（原来是反过来的）。这是拿两组真机
对照实验定下来的：先裁定的那组，扫描完立意又变了，旧的裁定结论就过期了，最后没发现一个
正在做同一件事的大型在研试验；先锻打的那组当场就抓到了它。

标书和论文模块的流程条也跟着改了（标书 5 格 → 6 格；论文多一格可选的「故事线锻打」）。

### 4. 综述表单：时间范围默认近 3 年，篇幅自己填

- 「时间范围」改了名字、默认值改成近 3 年（原来的默认太宽，检索结果一大半是老文献）。
- 「篇幅」从固定档位改成自由输入。
- 去掉了「下载 OA 全文」这个选项——它在综述这一步经常拖很久却用不上。

### 5. 科研作图：追问改图之后，看到的不再是上一版

在【科研作图】里让它改图，图确实改了、文件也重写了，但界面上显示的还是上一版——因为新图
和旧图同名，浏览器直接用了缓存。现在每次出图都带版本戳，改完立刻能看到新的。

## 升级注意

- 覆盖安装即可，**数据不会动**，老会话照常打开。
- 本版改到了后台程序，**必须装这个安装包**——只更新界面拿不到上面这些。
- 装之前请先退出正在运行的旧版，否则安装程序覆盖不了正在使用的文件。
- 如果你上一版停在 0.1.17 或更早，0.1.18 的内容也一并在这个包里，见
  [发布说明-0.1.18.md](发布说明-0.1.18.md)。
