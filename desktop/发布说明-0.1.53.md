# 0.1.53 发布说明

本版都在**文献研读**上：**一次能读好几篇**，并且**读得快多了**——同一篇指南，
一轮从 7 分半降到不到 2 分钟。

## 一、一次可以传好几篇，让它合着读

以前文献研读一次只收一篇。手上有三五篇同一个方向的文章时，只能一篇篇读完，
再自己在脑子里拼——而"这几篇到底哪儿一致、哪儿打架、谁更可信"恰恰是最费劲的那部分。

现在上传时可以一次选好几篇。进去之后，**左上角每份文件前面有一个勾选框**，
勾上要一起读的那几篇（至少两篇），右边模式条上多出来的两格就是给它们的：

- **多篇综合**——把勾中的几篇合成**一条总结论**（不是逐篇摘要拼起来）：一张纳入清单
  （每篇的研究类型、人群与样本量、干预、主要终点、核心数字、注册号），然后是一句话总结论、
  **哪些发现在多篇里互相印证**、**哪些互相矛盾以及可能是为什么**、合起来的证据有多强、
  这几篇共同没回答的问题。
- **多篇对比**——**一篇一列的对照表**，逐行比：研究设计、人群与纳排、样本量、干预与对照、
  主要终点及其定义、随访时长、统计方法、效应量（含 95%CI 与 p）、结论、注册号、
  资金与利益冲突、局限。表后面再逐条说清关键差异，并就每个主要终点判一句
  **一致 / 部分一致 / 冲突 / 不可比**，以及哪一篇的证据更硬。

两格的结论**每一条都要标出处**（哪一篇、第几节或哪张表）；原文没写的一律写"原文未报告"，
不会替你补，也不会引入你没传的文献。产物同时给 Word。

**导读 / 全文翻译 / 汇报 PPT 仍然只读左边当前那一篇**——勾选管的只是"综合 / 对比读哪几篇"，
文件条上会写明这件事。传了多篇时，各篇的导读、译文会各存各的文件，不会互相覆盖。

一句话取舍：**要某一篇的全部细节，还是单独跑那一篇的导读**；合并出的是跨篇结论，
单篇的次级指标数字它会略掉。反过来，跨篇的那些判断（哪儿印证、哪儿矛盾、谁更可信）
一篇篇分开读是得不到的。

## 二、快了很多

同一份文献（6 页的指南）做一次导读，实测**从 447 秒降到 116 秒**。省下来的时间来自两处：

**1）新增「思考档位」，在输入框下面的模型菜单里选**

同一个模型，"想多久再开口"是可以调的，而这件事对耗时的影响比换模型还大——实测默认
档位下，那一轮有七成时间花在模型自己想，而不是写给你看。现在明摆出来三档：

| 档位 | 什么时候用 | 说明 |
|---|---|---|
| **快** | 读文献 / 翻译 / 润色 | 照着原文做的活，实测快 3~8 倍，结论与引证不掉 |
| **标准** | 默认 | 模型自己决定想多久 |
| **深思考** | 方法学 / 统计 / 挑逻辑漏洞 | 尽量多想再答，慢但更稳 |

选过之后记住，不用每轮重选。

**2）上传完就把原文抽好**

以前是发问的时候才让模型自己去想办法抽正文——它要先找文件、问脚本怎么用、跑一遍、
发现产物名字不对再改名，来回五趟、五十秒，而脚本真正干活只有五秒半。现在上传完由软件
直接抽好，模型拿到的就是现成的正文。传了多篇就各抽一份，后面再问不会重抽。

扫描件这类抽不出字的，仍会如实告诉你要走文字识别，不会假装抽到了。

## 三、其他

- 文献研读里同一篇文章反复问时，不会再重复抽取正文。
- 修了一处发布流程上的说明错误（与使用无关）。
