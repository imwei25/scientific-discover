# 0.1.28 发布说明

> 修掉微信/企微里「连着发消息，中间那条回复变成空白」的问题；定时任务的推送可以指定只发企业微信或只发个人微信，不再两边都收到。

## 这版有什么变化

### 1. 修掉「连发消息时，中间那条回复是空的」（重要）

**症状**：在微信/企微里连着发好几条消息（前一条还没答完就接着发下一条），**排在中间的那条**会收到一片空白，而你的话其实已经被执行了 —— 于是你以为没生效，又重发一遍，同一件事被做了两次。

**原因**：处理上一条消息的后台进程在答完之后还要"收摊"零点几秒，而它收摊时发出的结束信号，被错当成了**下一条消息**已经结束 —— 那一刻新回复还没写出来，于是就成了空白。只有"排队后的第一条"会踩到，所以看起来时有时无。

这版从根子上修掉了：给每一轮对话加了独立编号，上一轮的结束信号再也影响不到下一轮。

**另外加了一层保险**：万一还是丢了，软件会在这一轮真正跑完后，**主动把完整回复补发给你**，并说明"刚才那条空白是软件的问题，你的指令已经执行"。

> 顺带一提：这个问题只影响**回复的送达**，你的指令一直都是被正常执行的。

### 2. 定时任务的推送可以指定发给谁

以前勾选「跑完把结果推送到我的微信/企业微信」后，**企业微信和个人微信会各收到一份**，界面上却看不出来会双发。

现在勾选框下面多了个**「推送到哪个」**下拉：

- **全部已连接的**（默认，与以前行为一致）
- **只推企业微信**
- **只推个人微信**

选项后面还会标出**「已连接 / 未连接」**，免得你选了一个其实没连上的，等任务半夜跑完才发现没收到。

另外，**在聊天里让它建的定时任务，现在只会推回你建它的那个平台** —— 在企业微信里建的，就不会再往个人微信也发一份。

### 3. 定时任务：出问题时能说明白

以前后台某一轮没跑起来时，你只会收到一片空白，无从判断该不该重发。现在会明确告诉你「这一轮没能启动起来，请把刚才那句话再发一次」，并且软件内部留下了排查记录。

## 升级方式

覆盖安装即可，数据、会话、已有产物都不动。
