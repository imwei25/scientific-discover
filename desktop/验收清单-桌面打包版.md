# 桌面打包版验收清单（SciAgent_0.1.0_x64-setup.exe）

> 用途：在目标电脑上逐项确认打包版一切可用。每项含【操作】【预期】【排查线索】。
> 日志位置：安装目录 `%LOCALAPPDATA%\SciAgent\bundle\app\serve.out / serve.err`（opencode 输出）；
> 网关端口 27821、opencode 端口 27822（仅本机 127.0.0.1）。
> 运行时完整性一键自检：`%LOCALAPPDATA%\SciAgent\bundle\runtime\git\bin\bash.exe %LOCALAPPDATA%\SciAgent\bundle\smoke.sh`
> （需先 `set REPO_ROOT=%LOCALAPPDATA%\SciAgent\bundle\app`，正斜杠形式），预期末行 ALL GREEN。

## B0. 云端账号（本包已预置站点地址 `cloud.json`，走这一组；不预置时才走 B 组）

> 前提：管理员在 `https://<站点>/admin` 建好账号，把**登录名 + 初始口令**给到使用者。
> 本机登录态存 `%LOCALAPPDATA%\SciAgent\bundle\app\web\cloud-state.json`（删掉它 = 回到未登录）。

| # | 检查项 | 操作 | 预期 | 排查线索 |
|---|---|---|---|---|
| B0-1 | 首启弹登录 | 全新安装后首次进入主界面 | 自动弹「登录云端账号」窗（不是模型 API 窗） | 没弹：`GET /api/cloud/status` 的 `configured` 是否为 true；为 false = 包里没有 `cloud.json` |
| B0-2 | 口令错 | 随便填个错口令 | 明确提示「账号或口令不正确」，不崩、不泄露账号是否存在 | |
| B0-3 | 首次登录强制改密 | 填管理员给的初始口令 | **1 秒内**切到「首次登录请修改口令」，不该干等几十秒 | 卡住 = 改密前误重启了后台 |
| B0-4 | 新口令校验 | 依次试：两次不一致 / 太短 / 无大写 | 三种都被明确拒绝 | |
| B0-5 | 改密完成 | 填合规新口令提交 | 提示会重启后台（约半分钟）→ 完成后页面刷新，不再弹任何窗 | |
| B0-6 | 账号面板 | 聊天框输入 `account` | 显示账号、档位、模型、今日/本月用量（带百分比）、可用技能 | `账号`、`cloud-config` 也认 |
| B0-7 | 真跑一轮 | 发一句「用一句话说明什么是随机对照试验」 | 十几秒内流式出结果 | 报 503 = 服务器没配上游 key；报 401 = 登录态失效 |
| B0-8 | 用量对得上 | 管理员在后台看该账号 | 出现刚才那次调用，模型/tokens/成本齐全 | 后台「用量」按钮 |
| B0-9 | 免登录 | 退出应用再打开 | **不再要求登录**，直接进主界面 | key 有效期内自动续期 |
| B0-10 | 停用即断 | 管理员后台停用该账号→在应用里再发一句 | 明确提示账号已停用/需重新登录，不是裸报错 | 恢复后重新登录即可 |
| B0-11 | 走自己的 API | 输入 `api-config` 填自己的 key 保存 | 顶部提示变「自定义 API…不计入平台额度」，出现「切回云端账号」 | |
| B0-12 | 切回云端 | 点「切回云端账号」 | 回到云端账号路由，按钮消失 | |
| B0-13 | 收到公告 | 管理员在后台「看板 → 公告」填一条、点发布 → 应用里等一会或切走再切回 | 顶栏下方出现横幅（提示蓝 / 警告黄 / 紧急红），文字与后台一致 | 最多 5 分钟；本机网关另有 60 秒缓存。没出现看 `GET /api/cloud/notice` 回了什么 |
| B0-14 | 公告点掉不再烦 | 点横幅上的「知道了」，再刷新页面 | 横幅消失且刷新后不再出现；管理员**改了公告内容**后重新出现一次 | 记的是公告 id，存 `localStorage.nm_notice_dismissed` |
| B0-15 | 催升级 | 后台公告里把「最低版本」填成比本包更高的版本号（本包版本见后台用户列表的「客户端版本」列） | 横幅多一行「请升级到 x.y.z 或更高版本」，填了下载地址时带一个「下载新版」链接 | 列里显示 `dev` = 这个包没注入 `APP_VERSION`（打包脚本问题），此时按设计不催升级 |
| B0-16 | 撤下公告 | 后台点「停止发布」，应用里切走再切回 | 横幅消失 | |

## 已知刻意降级（测到这些不算 bug，但要确认"降级得体面"）
1. **PDF 排版**（render-pdf-doc）：包内不带 LaTeX，需客户机装 MiKTeX 才有；预期是**明确提示+给 docx 替代**，不是无声失败。
2. **pptx/doc 在线预览**：包内不带 LibreOffice，预览提示不可用，下载不受影响。
3. 安装器未签名：SmartScreen 会拦一次，属预期。
