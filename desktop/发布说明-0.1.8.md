# 桌面版 0.1.8 发布说明（2026-08-04）

## 这一版为什么必须升

**旧站点地址 `weigu.duckdns.org` 已经在部分网络里被封了，且不可能解封。**

`duckdns.org` 是免费动态 DNS，在运营商与带审计的单位网络里被**按域名整片封禁**。
实测（`scripts/net-diagnose/probe-sni.ps1`，2026-08-04）：

- 打服务器 IP 的 80 端口，Host 写 `weigu.duckdns.org` → 立刻 RST；换任何别的 Host → 正常 308
- 大小写、带尾点、换个二级域名（`zzztest.duckdns.org`）照样 RST → 匹配的是 **duckdns.org 主域**
- 把同一个 Host 打到一台**无关服务器**也被 RST → 拦的是**域名字符串**，跟我们的服务器/IP 无关

宽松的网络只在明文 HTTP 层执行（用户还能用），严的网络连 TLS 的 SNI 一起匹配 ——
表现就是**「443 端口能连上，但 TLS 握手被掐断」**，浏览器打不开、桌面版报「连不上云服务器」。

## 这一版改了什么

- 站点地址换成 **`https://niuma.tellgen.com`**（自有域名，同一台服务器、同一个 IP，只换域名）
- 顺带带上「下一步建议」气泡的修复：思考模型会把 `max_tokens` 全花在推理上、正文空着回来，
  导致气泡闪两秒就消失。现在显式关思考 + 400 重试兜底，并在日志里留下线索。

## 用户怎么升

直接运行新安装包覆盖安装即可，**不用先卸载**。

- 登录态保留（`cloud-state.json` 跨升级不动），装完不用重新登录
- 产出与上传保留（`outputs\` / `uploads\`）
- 站点地址会被安装包里的新地址覆盖 —— 这正是本次升级的目的
- 在线更新过的技能包 / 界面包会被重置成本安装包自带的版本（装完可再从服务器拉最新）

## 不升会怎样

服务器上**新旧两个域名同时可用**，所以在没有封禁的网络里，老版本仍然能正常用。
但只要用户换到会封 duckdns 的网络（多数单位网、部分运营商），老版本就是连不上，且没有别的办法。

**旧域名计划在全部客户升级后摘掉**，摘掉前请确认没有还在用老版本的用户。

## 出问题时怎么定位

让用户双击 `scripts\net-diagnose\一键网络诊断.bat`，把生成的日志发回来：

- `[3/6] DNS 解析` 失败 → 域名解析被污染 / 被拦
- `[4/6] 直连 IP:443` 超时 → IP 或线路被拦（换域名无效，需换服务器地区或加中转）
- `[5/6] TLS 握手失败` → 按域名封禁（本次遇到的就是这个）

要进一步分清「拦域名」还是「拦 IP」，再跑 `二段诊断-SNI归因.bat`，它会直接给出结论。
