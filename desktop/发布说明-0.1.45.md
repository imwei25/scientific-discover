# 0.1.45 发布说明

本版两处都在「看得见的地方」：产出栏别再拿一堆过程文件冒充成果，选文件夹时别让你盲选。

## 一、做 PPT 时，几十个中间 SVG 不再混进「产出」主区

做一份 PPT，出片过程会写出几十个 SVG（逐页草稿、定稿、整份备份），真正要交到你手上的只有那份 `.pptx`。
此前这些 SVG 全都和 `.pptx` 并排站在产出栏最上面，交付物被淹在里面。

现在：**子目录里的 SVG 一律归入「中间文件」折叠块**，主区只剩 `.pptx` 和大纲。

- **什么都没有被藏起来**——折叠块带着计数，点一下就全在，也照常能下载。
- 只收窄 SVG，**不动 png/jpg**：你在对话里让 AI 出的图还是照旧摆在主区。
- 会话根目录里的 `.svg`、以及 `figures/` 里的图，仍然是主产物（那是作图技能交付图的约定位置）。
- 「推送到微信 / 企微」走的是同一套判据，所以那边也不会再一次性轰给你一堆 SVG。

## 二、选文件夹时，能看见里面有哪些文件了

文献管理里选「要整理哪个文件夹」，以前只列子目录。而文献文件夹十有八九**没有**子目录，
于是弹窗里只有一句"这里面没有子目录"——你根本没法确认自己站在的是不是那个文件夹，只能选了再回头看结果对不对。

现在文件也一并列出来（带文件大小），**但一律淡显、点不动**：

- 鼠标移上去会告诉你「请选择一个文件夹进行整理」——文件只是给你**认地方**用的，不能被选中。
- 文件多的时候最多列 200 个，并注明"另有 N 个文件没有列出"；**这只影响这里的预览，整理时一个都不会漏**。
- 这个弹窗同时也是普通对话里的「选择工作目录」，那边同样能看见文件了。

## 升级方式

覆盖安装即可，配置与会话都保留。
