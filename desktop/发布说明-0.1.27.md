# 0.1.27 发布说明

> 修掉画图 / 统计技能"找不到 Python 环境"的假警报（会白等十几分钟那个）；技能包也能自己更新和回退了；定时任务与微信推送三处真机修复；识图入口重做，PDF 可以整份识别了。

## 这版有什么变化

### 1. 修掉「作图 / 统计说找不到 Python 环境」的假警报（重要）

**症状**：让它画图、做统计、查引用时，它报「找不到 .venv / 缺 Python」，然后自己去重装一遍
Python 依赖 —— 一等十几分钟，最后可能还是不成。

**真实原因**：软件装在 `Niuma Science` 这个文件夹里，**名字中间有个空格**。技能里的命令没给路径加引号，
系统就从空格处把路径切成了两半，报「找不到文件」。**Python 环境自始至终都是好的**，它只是被这个报错骗了。

这版从三处一起堵死：

- 内部路径改用不含空格的等价写法；
- 所有技能命令统一加引号；
- 明确告诉它：见到这个报错是引号问题，**不准去重建环境、不准重装依赖**。

同时**移除了「环境初始化」技能** —— 打包版的 Python 环境是随安装包装好的，不可能缺，
留着它只会在误判时被叫起来白烧时间。

> 如果你之前手工装过一遍依赖：不用管，也不用卸，新版不会再走那条路。

### 2. 菜单里的「界面版本」升级成「版本管理」——技能也能自己更新回退了

以前只有界面能在线更新。现在技能（写作、检索、作图、统计这些**能力本身**）也能：

- 有新版技能时给提示，点一下就换过去，**不用重装软件**；
- 换完发现不对劲，**一键回退到上一版**，本地留最近 5 版；
- 出厂自带的那版永远保底，回退不会把你退到"什么都没有"。

菜单入口从「界面版本」改叫「版本管理」，界面和技能两条线在同一页里看。

### 3. 定时任务与微信/企微推送：三处真机修复

- **到点跑任务时不再闪黑框**——改用隐藏启动器，后台安静跑完。
- **推送加了看门狗**：投递失败不再石沉大海，会在软件里留一条通知告诉你哪次没送到、为什么。
- **聊天里只推主产物**：以前一次跑完会把中间文件、临时脚本一股脑发到微信，几十条刷屏；
  现在只发成稿、图表这类**你真正要的东西**。

### 4. 识图（OCR）入口重做，PDF 可以整份识别了

- 入口从 bash 换成 Python，并补了 PowerShell 壳 —— 修掉部分机器上"点了没反应"。
- **PDF 支持逐页转图识别**：整份扫描件 PDF 可以直接丢给它，不用自己先截成图片。

> 识图结果仍属"待核信号"：编号、金额、批号这类关键字段请自己再看一眼，别直接采信。

### 5. 文献管理：可以按你勾的格式整理

- 整理结果除了 Excel 台账，还能按勾选出 **md / txt / 自定义格式**。
- 非文献类文件单独列「主要内容」，不再硬塞进文献表里凑数。
- 整理完可以**直接移进工作台**接着往下用。

## 升级方式

覆盖安装即可，数据、会话、已有产物都不动。
