# 0.1.26 发布说明

> 新增「文献管理」模块；产出栏分主次不再一片混乱；查引用会告出「这篇正文压根没引」；修掉「选了工作目录的对话在左边找不到」。

## 这版有什么变化

### 1. 新增「文献管理」模块（核心能力）

选一个**你电脑上存放文献的文件夹**，它把里面的 PDF / Word 逐份读完，出一张 Excel 台账：

- **一类一个 sheet，sheet 名就是类名**；每行一篇文献，列是 文件名 / 标题 / 年份 / 作者 / 杂志 / 核心观点。
- 分类标准**你可以自己写**（例如"按研究类型分：RCT / 队列 / 病例对照 / 综述"）；留空就由它读完后
  自己定一个口径，并在交付时告诉你是按什么分的；也可以选择**不分类**，全部放一个 sheet。
- 抽不到的字段一律写「原文未标注」——文件名叫 `Nature_2021.pdf` 既不证明它发在 Nature，
  也不证明是 2021 年，这类地方它不替你猜。图片型扫描件会被单独标出来。

**它直接读你原来的文件夹**，不复制、不上传，几百篇也是点一下就选好；生成的 Excel 也写在那个文件夹里。

### 2. Excel 可以按 sheet 预览，还能直接在预览里改分类、一键归档

- 产出栏点开 `library.xlsx`，右半屏是**页签 + 表格**（以前 Excel 只能下载，或者被转成一长串 PDF 页、列宽全乱）。
- 每行末尾有个**分类下拉**：把某一篇改到别的类（或新建一类），Excel 立刻重出，不用再跟它说一句话。
- **「按分类归档到子文件夹」**：把原文件按类名归进子文件夹。它会**先把"哪个文件移到哪儿、共几个"列给你看**，
  你点了「移动过去」才真动文件；不放心可以选「复制过去」（原件留在原地），移动过的还能**一键撤销**。

### 3. 产出栏分三段：主产物 / 中间文件 / 文件夹里原有的

以前一次综述或成稿跑完，右边"产出"里几十个文件平铺——成稿混在一堆中间脚本、日志、临时表里找不着。现在：

- **主产物**（成稿、图、表、报告）排在最上面，一眼就能拿；
- **中间文件**折叠起来，需要时点开，一个都没少；
- 选了工作目录的对话还多一段**「文件夹里原有的」**——你本来就放在那儿的文件不再冒充这次的产出。
- 「打包下载」只打这次做出来的东西，**不会**把你原有的文件一起打进去。

### 4. 修复：选了工作目录的对话在左边列表里看不见

这是个一直存在的老问题，只是「文献管理」每次都要选文件夹，才把它顶了出来：**凡是给对话指定过工作目录的，
那条对话都不会出现在左侧列表里**，「文件夹」分组也跟着空着，看起来像对话丢了（其实一直都在）。

同一个原因还带来另外两处，一并修好：

- 后台整理时会把这些对话的内部记录当成"已经不存在的残留"清掉；
- 这类对话的花费统计漏算了一部分。

> **已经被清掉记录的老对话恢复不了**（记录本身已经没了）。本版之后新建的都正常。

### 5. 查引用：多一列「这篇在正文哪一段被引用」，正文没引过的直接告出来

以前查引用只回答"每一条是不是真文献"。但还有一类错它答不了：**参考文献表里躺着一条正文压根没引过的文献**
——改稿时把正文那句删了、文献却留在表里，或者凑参考文献数多列了几条。这类条目**逐条查全是真的、报告一片绿**，
而投稿时编辑一眼就能看到（同时"本文共引 N 篇"也就不成立了）。

只要你把**正文**一起给它（稿件全文 `.md`/`.txt`/`.docx` 都行；流程里自动成稿的会自己带上），报告里就会：

- 每条文献多一列**正文引用位置**，写成「引言¶1、讨论¶3」这样——节名 + 那一节的第几段，直接翻过去核；
- **正文里找不到的**单列一节「未被正文引用」，并说清两种改法：在正文该出现的地方引上，或从表里删掉
  （删了要重排编号并重新跑一遍）；
- 反过来的错也一起告：正文里写了 `[7]`、参考文献表却只有 6 条，这种**悬空编号**同样列出来。

认得出 `[3]`、`[3,5]`、`[3-6]`、`【3】`、上标数字，也认作者-年份那种写法（`Finn et al. (2020)`）。
**如果你的正文是从 EndNote / Zotero 直接导出、编号还是"域代码"或图片**，它认不出标记——这种情况它会
**明确告诉你这一列不可信、并且不判定任何一条"没被引用"**，而不是甩给你一张"全部都没引用"的错表
（照着那种表删，会把整份参考文献删掉）。

## 升级注意

- 覆盖安装即可，**数据不会动**，老会话照常打开。
- 本版改到了后台程序，**必须装这个安装包**，界面包更新不到。
- 装之前请先退出正在运行的旧版（若缩在托盘里，右键「完全关闭」），否则覆盖不了正在使用的文件。
- 「文献管理」里那个文件夹**只能在对话开始前选**，开始之后要换文件夹请新建对话。
- 更早版本的内容也一并在这个包里，见 [发布说明-0.1.25.md](发布说明-0.1.25.md)。
