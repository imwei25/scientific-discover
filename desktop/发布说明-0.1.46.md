# 0.1.46 发布说明

本版都在数据模块那一屏：结果不再被挤没，图也真的会画出来。

## 一、「变量对应」不再把结果区挤成一条缝

数据模块里点开「变量对应」核对列名之后，它会一路撑到屏幕底下——七个下拉、一整排协变量、
一张前几行预览。而结果正文、产出列表、追问入口全在它下面那一格里，于是被压成**一条一行高的缝**：
跑完了什么都看不见，产出也摸不着。

现在：

- 「变量对应」最多占面板的 **42%**，超出部分在它自己里面滚，标题栏吸顶，滚起来也知道在哪一块。
- 下面那格给了高度下限，**再也不会被压没**。
- **点「开始」时它自动收起来**——核列名是跑之前的事，跑起来该让位给结果。想改回来点一下标题就展开，
  填好的值一个都没丢；缺列时它仍会自动顶开并标红。

## 二、图片产出直接铺出来，不再只是一行文件名

此前一张 `plot_km.png` 在产出栏里的样子，和一份 csv 完全一样：一行文件名 + 一颗眼睛按钮。
图出了，但屏幕上没有任何一个像图的东西。

现在图片产出**直接铺成缩略图**，点一下仍是原来的大图预览 / 下载。
（脱敏对照表这类不允许在界面里展示的文件不受影响，照旧只给下载。）

## 三、「统计分析」现在会顺手出预览图

以前点完「统计分析」，交回来的是一篇纯文字报告：数字全在文字里，生存曲线、ROC、分布对比一张都没有。
要看一眼 KM 曲线，得再去点「出版级图」等一轮 300dpi 出片。

现在这一步**每个主分析都配一张 150dpi 预览图**：

- 组间比较 → 箱线 / 小提琴；生存 → KM 曲线（含风险人数表）；ROC → 曲线含 AUC 与 95%CI；
  回归 → 森林图；相关 / 一致性 → 散点或 Bland-Altman。
- 图会**列在「统计分析」这一格自己下面**（此前就算画了也匹配不上契约，会掉到「智能助手」那格去，
  没人会去那儿找）。
- 这里出的是**看数用的**预览图。要 300dpi + 矢量的投稿图，仍然点「出版级图」——两边分开放，互不覆盖。
- 图上的每个数仍然只能来自真实算出来的结果。
