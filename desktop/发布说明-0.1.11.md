# 0.1.11 发布说明

## 这版改了什么

**四个「核心能力」模块换成了同一种用法**：文献研读、文稿核查与审校、文章润色、数据统计与分析。

以前它们和综述、标书、论文一样，走的是「填一张表 → 看流程条一步步走 → 一条对话流」。
但这四个模块的输入其实都是**一份东西**（一篇文献 / 一份稿件 / 一张数据表），而你想对它做的事
有好几种、彼此没有先后、随时想来回切。塞进流程条里的结果是：条子永远停在「共 N 步、已完成 1 步」，
而那份东西本身在界面上没有地方摆。

现在进这四个模块，看到的是：

- **左边**常驻你传上来的那份东西（PDF / Word 原样翻页；数据表直接渲染成表格）
- **中间**是助手
- **右边**一列模式按钮，点哪个做哪件事，随时切回来看之前那次的结果

| 模块 | 传什么 | 能做的几件事 |
|---|---|---|
| 文献研读 | 一篇 PDF / Word | 文献导读 · 对着原文追问 · 全文翻译 · 汇报 PPT |
| 文稿核查与审校 | 一份稿件 | 引用核查（真伪 / DOI / 撤稿）· 方法与统计审校 · 数据完整性 · 追问 |
| 文章润色 | 一份稿件 | 润色改写 · 改动对照（逐条看它改了什么）· 排版出件 · 追问 |
| 数据统计与分析 | 一张 xlsx / csv | 数据体检 · 基线表 · 统计分析 · 出版级图 · 源数据自查 · 追问 |

各模式**共享同一个会话**，所以原文只解析一次；切到「智能助手」时，前面翻译过什么、做过什么图，
上下文原样都在，接着问就行。换一份 = 新开会话。

## 几个刻意的设计

**统计模块保住了列名映射。** 「列名认错」是这个模块最高频的失败模式，而且不会报错——你表里
`随访时间` 和 `入院时间` 并排，认错了只会给你一份看起来很正常的错 KM 曲线。所以那几个下拉留着，
收进一张默认折叠的「变量对应」面板，候选直接读自你表的真实表头。点某个分析时如果缺了它必需的列，
面板会自动展开并把缺的那格标红，而不是发出去让模型自己猜。

**做不了的事会当场说清楚，而不是假装能做。** 例如没传配套数值表就点「数据完整性」，界面会告诉你
缺什么、为什么需要它，并就地给一个上传按钮——不会让你点了按钮却毫无反应。

**该守的底线写进了每一轮。** 润色不动数字、单位和结论强度（「显著低于」不会被改成「低于」）；
带文献角标的整句默认逐字保留（那是在转述别人的结论）；统计里声明过「含患者身份信息」的表，
每一轮都会先脱敏再分析。这些以前只在第一轮生效，现在每轮都跟着走。

## 升级注意

- 这版只改了界面与提示词，**不涉及数据格式**，老会话照常打开。
- 旧版「文献研读」（检索一个方向的文献那种）留下的会话，在新界面里打不开——它们没有上传件。
  界面会说明一句，那些会话的对话记录仍然可以从「自由对话」那边翻到。
